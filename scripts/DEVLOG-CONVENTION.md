# DEVLOG運用ルール

このリポジトリでの作業は、力学シリーズに限らず全ての教材・スクリプト変更において、
セッションの最後に必ず以下を行う。

1. リポジトリ直下の `DEVLOG.md` に、そのセッションでの作業内容を1エントリ追記する
2. 変更ファイルをコミットする
3. `git push` でGitHubに反映する

この3点セットを行うまで、そのセッションの作業は完了していない。

## エントリ形式

```
## <日付> — <作業内容の短い見出し>
- 変更: <変更・新規作成したファイルのパス>
- 教材数: <化学N件・物理N件、合計N件>
- 保留: <未着手・要確認事項があれば>
- 次: <次にやるべきこと、あるいは「特になし」>
```

- 日付は `YYYY-MM-DD` 形式
- 「変更」は `html/xxx.html`, `data/xxx.json` のようにリポジトリルートからの相対パスで列記する
- 「教材数」は `html/` 直下の `.html` ファイルを対象に、化学系・物理系(生化学系を含む)を数える
- 「保留」「次」は該当がなければ「特になし」と書く。存在しない項目を無理に作らない
- エントリは末尾に追記する(新しいものが下に来る)
