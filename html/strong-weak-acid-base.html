STRONG / WEAK · DISSOCIATION · 01

強酸と弱酸、強塩基と弱塩基
電離度・濃度依存性・pHの出方

物質収支と電荷収支から立てた厳密式を二分法で解き、高校で使う近似式と並べて表示します。近似が破綻する境界も同じ計算から出しています。医学部受験向け。

EXACT FORMULATION

厳密式

1価の弱酸 HA を全濃度 C で溶かす。存在する化学種は HA、A⁻、H⁺、OH⁻ の4つなので、独立な式も4本必要です。

物質収支 C = [HA] + [A⁻] 電荷収支 [H⁺] = [A⁻] + [OH⁻] 酸解離 Ka = [H⁺][A⁻] / [HA] イオン積 Kw = [H⁺][OH⁻]

h = [H⁺] と置いて消去する。電荷収支から [A⁻] = h − Kw/h、物質収支から [HA] = C − h + Kw/h。Ka の式に入れて分母を払うと3次方程式になります。

h³ + Ka·h² − (Kw + Ka·C)·h − Ka·Kw = 0

ただし数値解にはこの形を使いません。[A⁻] = C·Ka/(Ka + h) と閉じた形で書けるので、電荷収支に戻すと

g(h) = h − Kw/h − C·Ka/(Ka + h) = 0

3項とも h について単調増加。したがって g(h) は狭義単調増加で、解はただ1つ、二分法が失敗しません。h = 10⁻¹⁶ 〜 10² で符号変化を挟むだけで済み、Newton 法のような初期値依存もない。このページの数値はすべてこの式を 90 回二分して出しています。

多価・塩基への一般化

Ka の配列から平均プロトン解離数 z̄(h) を作れば、同じ形のまま多価酸に伸びます。塩基は共役の関係で裏返すだけ。強酸・強塩基も Ka = 10⁶ / Kb = 10⁶ を入れて同じ経路で解いているので、コード上に場合分けがありません。

酸 g(h) = h − Kw/h − C·z̄(h) = 0 塩基 g(h) = h + C·z̄ᵦ(h) − Kw/h = 0 z̄ : uⱼ = uⱼ₋₁·Kaⱼ/h から Σj·uⱼ / Σuⱼ z̄ᵦ : vⱼ = vⱼ₋₁·Kbⱼ·h/Kw から Σj·vⱼ / Σvⱼ

高校で使う近似

近似① [OH⁻] ≪ [A⁻] かつ α ≪ 1 h = √(Ka·C) pH = ½(pKa − log C) α = √(Ka/C) 近似② [OH⁻] のみ無視（オストワルドの希釈律） h² + Ka·h − Ka·C = 0 Ka = C·α²/(1 − α)

近似①と②のずれは ΔpH = −½·log(1 − α)。α = 0.1 でも pH は 0.02 しか動きません。ところが α 自体のずれは大きく、α = 0.3 で √(Ka/C) は 0.36 を返します。pH は鈍感、電離度は敏感。この非対称が下の数値パネルで確認できます。

pKa / pKb を直接入力

問題文で Ka が与えられている場合はここに pKa = −log Ka を入れて差し替えてください。物質リストは配列1本で管理しているので、コード側に追記しても同じように増やせます。

pH vs CONCENTRATION

希釈曲線

横軸を指でなぞるかスライダーを動かすと全パネルが連動します。破線の横線は中性 pH 7、縦線は C = K（電離度がちょうど 1/2 になる濃度）。

DEGREE OF DISSOCIATION

電離度

α = 1 − 未電離分率。1価なら教科書の電離度と一致し、多価では「1個以上プロトンが動いた分率」を表します。希釈すると弱酸でも α が 1 に近づく、これがオストワルドの希釈律。
