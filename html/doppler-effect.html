DOPPLER EFFECT

ドップラー効果インタラクティブ

音源が動くと波長が変わり、観測者が動くと波面をまたぐ回数が変わる。別々の理由で起きているのに、式では分母と分子に分かれて同居している。ここを分けて見ておくと、風が入っても斜めに通過しても、超音波で血流を測る場面でも同じ式で押し通せる。

WAVEFRONTS

音源が一定の間隔で出した波面を、そのまま同心円で描いている。円の中心は出した瞬間の音源の位置に置き去りになり、音源だけが先へ進む。だから前は詰まり、後ろは開く。

波面（1 周期ごと） 音源 観測者 衝撃波面 波長の実測

OBSERVED FREQUENCY

式の文字に触れると、それがどの速度で、上の図のどこにいるかが分かる。押すと固定、もう一度押すと解除。

符号で迷わないための一手

正の向きを「音源から観測者へ向かう向き」に固定してしまう。あとは vs、vo、w をその向きの成分としてそのまま代入するだけで、近づく離れるを考える必要がなくなる。観測者が音源の反対側に回り込んだら、正の向きも一緒に反転する。

RULE
正の向き = 音源 → 観測者　　f′ = f0(V + w − vo) / (V + w − vs)

分子が観測者、分母が音源。取り違えたら「音源が音速に近づくと分母が 0 に近づいて f′ が発散する」を思い出せばいい。観測者がどれだけ速く走っても f′ は発散しない。この非対称が分母と分子の割り当てを決めている。

1 次近似で済ませたときの誤差

Δf/f0 ≒ (vs − vo)/V は暗算には便利だが、速度が音速の 10% を超えると効いてくる。音源が動く場合と観測者が動く場合の差も、同じところから出てくる。

SHOCK WAVE

音源が空気に対して音速を超えると、どの波面にも共通の接線が引ける。τ が約分で消えるので、円錐の角度は経過時間によらない。

ソニックブームが届くまで

頭上を通り過ぎてから轟音が届くまでには間がある。円錐が斜めに引きずられているぶんだけ遅れる。高度 h、マッハ数 M なら、機体が水平に h√(M2−1) だけ進んだところで地上に届く。

上の表は成層圏の音速を使っている。高度 10 km では気温が −50°C 前後まで下がり、音速は 300 m/s 程度。地表の 340 m/s で計算すると遅れ時間を 1 割ほど短く見積もる。

FLY-BY · 遅延時間の数値解

音源が横を通り過ぎる場合、いま聞こえている音は過去の位置から出ている。発射時刻と受信時刻を結ぶ方程式を解かないと、振動数の時間変化は出せない。ここは閉じた式に頼らず、遅延時間の 2 次方程式を解いて数値微分している。

WAVEFRONTS · 3D

上空を飛ぶ音源の波面を球として描き、地面との切り口を同時に出している。地上に現れる円の並びの縁が、そのままブームの届く境界になる。ドラッグで視点が回る。

視点

DOPPLER ULTRASOUND

超音波で血流を測るとき、血球はまず動く観測者として音を受け取り、次に動く音源として散乱する。ドップラー効果が 2 回かかるので、片道の 2 倍の周波数差が出る。

角度が大きいと何が起きるか

補正をかけずに測ると見かけの速度は cosθ 倍になる。圧較差は速度の 2 乗で効くので cos2θ 倍。帯は角度を 5° 読み違えたときの誤差の幅で、θ が大きいほど急に広がる。

DERIVATION

波長が変わる側と、数える回数が変わる側

音源が振動数 f0 で鳴りながら速さ vs で動き、空気全体が速さ w で流れている。正の向きは音源から観測者へ向かう向きにとる。周期 T = 1/f0 のあいだに、直前の波面は地面に対して (V+w)T 進み、音源自身は vsT だけ追いかける。差が波面の間隔になる。

WAVELENGTH
λ前 = (V + w − vs) / f0　　λ後 = (V − w + vs) / f0

観測者から見た波面の接近速度は (V + w) − vo。この速さで間隔 λ前 の列を横切るので、単位時間に出会う波面の数は割り算で出る。

GENERAL
f′ = {(V + w) − vo} / λ前 = f0 (V + w − vo) / (V + w − vs)

近似はどこにも入っていない。ここまでは音源と観測者が一直線に並んでいることだけが条件で、速度が音速に近くても成り立つ。

風が消えるとき、消えないとき

w は分子と分母に同じだけ入る。二人とも止まっていれば約分されて f′ = f0。風だけではドップラー効果は起きない。動いている人がいるときだけ、風は「音速が V+w に変わった」形で効く。

TAILWIND
V = 340、vs = 30、vo = 0 のとき　w = 0 で f′/f0 = 1.0968、追い風 w = +30 で 1.0882

追い風だと変化が小さくなる。波が速く逃げるぶん、同じ 1 周期で音源が詰められる割合が減るから。向かい風なら逆に大きくなる。「風で音が高くなる」は間違いで、風は変化の効き方だけを変える。

音源と観測者は対等ではない

同じ速さ u で近づく場合を比べる。音源が動くなら V/(V−u)、観測者が動くなら (V+u)/V。1 次までは両方 1 + u/V で一致するが、そこから先がずれる。

EXPANSION
V/(V−u) = 1 + u/V + (u/V)2 + …　　(V+u)/V = 1 + u/V

差は (u/V)2 から。V = 340、u = 34 で 1.111 対 1.100 の 1.0% 差、u = 100 で 9.5%。速度が音速の何割かを 2 乗した分だけ食い違うと覚えると早い。分母が 0 になりうるのは音源側だけで、この非対称が式の形そのもの。光では媒質がないので、この差は消えて相対速度だけで決まる形になる。

斜めに通過するときの遅延時間

一直線の式は、真正面から来るときにしか使えない。横を通り過ぎる音源では、いま耳に届いた音は過去の位置から出ている。発射時刻 te と受信時刻 t を結ぶ条件を書く。発射点 P、経過時間 τ = t − te、観測者の位置 X(t)、風 w として、波面が観測者に触れる条件はこうなる。

RETARDED
|X(te+τ) − P − wτ| = Vτ
QUADRATIC
(|u|2 − V2)τ2 + 2(D·u)τ + |D|2 = 0　　u = vo − w、D = X(te) − P

|u| < V なら 2 次の係数が負で、根の積 |D|2/(|u|2−V2) も負。だから正の根がちょうど 1 つに決まる。閉じた形で解けるので、あとは受信時刻を発射時刻の関数として並べるだけ。

FREQUENCY
fobs = f0 · dte/dt = f0 / (dt/dte)　　分母は中心差分で数値微分

一直線に並べて計算させると、上の閉じた式と小数点以下 10 桁まで一致する。FLY-BY のカードにその照合を出してある。数値微分で出した fobs を受信時刻で積分すると発射した波面の総数に戻るので、二重の検算になる。

教科書がよくやる「受信した瞬間の音源位置で角度をとる」は、この遅延を無視した近似。振動数が f0 を横切るタイミングが最接近距離 d を音が渡る時間だけずれるので、通過音の前後の非対称として現れる。d が大きく vs/V が大きいほど差が開く。

音速を超えたら

音源が空気に対して持つ速さは vrel = vs − w。時刻 te に出た波面は半径 Vτ、その中心から現在の音源までの距離は |vrel|τ。音源から円に接線を引くと、直角三角形の斜辺が |vrel|τ、対辺が Vτ になる。

MACH
sinμ = Vτ / (|vrel|τ) = V/|vrel| = 1/M　　M = |vrel|/V

τ が約分で消えるのがここの急所。どの波面に対しても同じ角度になるので、接線が全部そろって 1 枚の面をつくる。M = 1.2 で μ = 56.4°、M = 1.5 で 41.8°、M = 2 で 30°。速いほど円錐は細くなる。

前方に置いた観測者に対しては、式の分母 V + w − vs が負になる。負の振動数に物理的な意味はないが、遅延時間の方程式では dt/dte < 0 に対応していて、あとから出た音が先に届くことを表す。実際に音源が通り過ぎるまで何も聞こえず、通り過ぎた瞬間に、それまでの音がひとまとめに、しかも時間を逆順にして届く。

壁の反射は 2 回のドップラー

静止した音源が f0 を出し、速さ u で近づく壁がそれを跳ね返す。壁はまず動く観測者、次に動く音源として働く。

STEP 1
f1 = f0 (V + u)/V　　壁が受け取る振動数
STEP 2
f2 = f1 · V/(V − u) = f0 (V + u)/(V − u)

元の音と重ねると毎秒 |f2 − f0| = 2f0u/(V−u) 回のうなりが出る。この 2 段構えが、そのまま超音波ドップラーの原理になる。

超音波ドップラーで血流を測る

探触子は静止していて、組織中の音速は c。血球が速さ v で、ビーム方向と角度 θ をなして流れている。ビーム方向の速度成分は v cosθ。探触子に近づく向きを正にとる。

RECEIVE
f1 = f0 (c + v cosθ) / c　　血球は動く観測者
SCATTER
f2 = f1 · c / (c − v cosθ) = f0 (c + v cosθ)/(c − v cosθ)　　血球は動く音源
SHIFT
Δf = f2 − f0 = 2 f0 v cosθ / (c − v cosθ)　　厳密
CLINICAL
Δf ≒ 2 f0 v cosθ / c　　装置が使う形

落としているのは分母の v cosθ だけ。v = 1 m/s、c = 1540 m/s なら比率は 6.5×10−4 で、速度に直すと装置は 0.065% だけ過大に出す。無視して構わない大きさだが、どこを落としたかは押さえておく。係数の 2 は往復で 2 回ドップラーがかかることから来ていて、ここを 1 にすると速度が半分になる。

INVERT
v = Δf · c / {cosθ (2f0 + Δf)}　　厳密　　装置は v ≒ Δf c / (2 f0 cosθ)

cosθ で割り戻す、その落とし穴

角度補正をかけずに θ = 0 とみなすと、見かけの速度は真の値の cosθ 倍になる。60° で半分。ここに簡易ベルヌーイ式 ΔP = 4v2 を通すと、圧較差は cos2θ 倍で 4 分の 1 まで落ちる。

UNDER
v見かけ = v cosθ　　ΔP見かけ = 4v2cos2θ

真の 4.0 m/s（圧較差 64 mmHg、重症の大動脈弁狭窄）が 60° で 2.0 m/s、16 mmHg。数字だけ見れば軽症に化ける。速度が 2 乗で効く指標を扱うときは、角度のずれが二重に効くと考えたほうがいい。

補正をかけても角度の推定そのものに誤差が残る。相対誤差は cosθ/cos(θ+Δθ) − 1 で、Δθ = 5° なら 20° で 3.7%、45° で 10.0%、60° で 18.3%、70° で 32.2%。tanθ·Δθ という目安は 60° で 15.1% と出るので、大きい角度では目安のほうが甘めに出る。θ ≤ 60° に収めるという臨床の作法はここから来ている。θ = 90° では cosθ = 0 で、どれだけ速く流れていても信号が出ない。

パルスドップラーの折り返し

パルス波では 1 秒あたりの送信回数 PRF でしか波形を標本化できないので、ナイキスト周波数 PRF/2 を超える Δf は折り返して逆向きに見える。深さ d まで往復する時間が必要なので PRF は c/(2d) が上限。

NYQUIST
vmax = c · PRF / (4 f0 cosθ) = c2 / (8 d f0 cosθ)

c = 1540、深さ 5 cm、5 MHz、θ = 0 なら 1.19 m/s。弁狭窄の 4 m/s は到底測れない。周波数を下げるか、連続波ドップラーに切り替えるか、ベースラインをずらすことになる。振動数を上げると感度は上がるが測れる速度の上限は下がる、というのがこの式の読みどころ。

NOTES

どの近似がどこで効くか

使った定数

空気中の音速は 15°C で 340 m/s を既定にした。断熱式 V = √(γRT/M) に γ = 1.4、M = 28.9647 g/mol を入れると 0°C で 331.32 m/s、15°C で 340.30 m/s。教科書の V = 331.5 + 0.6t は 15°C で 340.5 m/s で、0.06% ほど高い。0°C 乾燥空気の実測は 331.29 m/s（Wong 1986）で断熱式とほぼ一致するので、教科書の 331.5 のほうが古い測定に由来する丸めと見ていい。ドップラーの計算では音速そのものより速度の比が効くので、この程度の差は結果をほとんど動かさない。

組織中の音速は 1540 m/s を既定にした。これは装置が距離換算に使っている軟部組織の平均値で、実測は血液 1570、骨格筋 1580、肝 1550 前後、脂肪 1450 とばらつく。教科書には 1500 と書かれていることもあるが、装置の表示と突き合わせるなら 1540 を採るべき。皮下脂肪の厚い被検者では深さ表示が数% ずれるのはこの食い違いのせい。速度計測のほうは Δf と c が比例するので、c を 1450 で計算すると速度も 6% 小さく出る。

大動脈弁狭窄の重症度の目安（最大流速 4.0 m/s、平均圧較差 40 mmHg）と簡易ベルヌーイ式 ΔP = 4v2 は臨床ガイドラインの慣用値。ΔP = 4v2 自体、粘性損失と近位側の流速を落とした近似で、狭窄が軽いときほど誤差が大きい。

取り違えやすいところ

  • 音源が動いても波長が変わるだけで、音速は変わらない。音速を決めるのは媒質の温度だけ。「速い音源からは速い音が出る」は誤り。
  • 観測者が動いても波長は変わらない。変わるのは 1 秒あたりに何本の波面をまたぐか。ここを混ぜると分母と分子を取り違える。
  • 風が吹いても、二人とも止まっていれば振動数は変わらない。変わるのは波長と、地面に対する音の速さ。
  • 分母が 0 に近づくのは音源側だけ。観測者がどれだけ速く走っても f′ は発散しない。
  • 音源が遠ざかるときの f′ は f0V/(V+vs) で、近づくときの f0V/(V−vs) と平均しても f0 にならない。高いほうへ寄る。
  • 斜めに通過する音源では、真横に来た瞬間に f′ = f0 にはならない。音が届くまでの遅れのぶん、少し後になる。
  • マッハ角は音源の速さだけで決まり、経過時間にも音源からの距離にもよらない。
  • 超音波ドップラーの係数 2 は往復で 2 回かかるから。片道の式で計算すると速度が半分になる。
  • cosθ で割り戻すのは補正であって、測定値そのものではない。角度の入力を間違えるとその比でまるごとずれる。
  • θ = 90° で信号が消えるのは血流が止まったからではない。ビームに垂直な流れは原理的に見えない。
  • 血管断面の平均流速は最大流速の半分程度（層流の放物線分布）。最大流速から流量を出すと 2 倍になる。
