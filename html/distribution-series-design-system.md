# 分布曲線シリーズ デザインセット

acid-base-distribution.html（リン酸・炭酸・24系統合版）で使用したデザイントークン一式。
yASAKAブランドガイドライン（ネイビー×クリーム、Noto Serif JP＋Cormorant）とは別系統。
理系の資料・データ可視化・インタラクティブ教材で再利用することを想定。

---

## 使いどころ

- 化学・物理・生物などの数値データを扱うインタラクティブ教材
- 存在率／濃度／pHのような連続量をグラフとテーブルで並べて見せる資料
- 「静かな実験ノート」のトーン。彌榮ブランドを明示的に指定されない限り、こちらがデフォルト

## カラートークン

```css
--ink:        #16232B;  /* 本文・見出し */
--muted:      #5E6E76;  /* 補助テキスト・ラベル */
--paper:      #EDF1EF;  /* ページ背景（薄いグレイグリーン） */
--surface:    #FFFFFF;  /* カード背景 */
--rule:       #D6DDDA;  /* 罫線・枠線 */
--rule-soft:  #E8EDEB;  /* グリッド線・表の区切り */
```

### 系列カラー（電荷段階ごと）
彩度を落とした顔料寄りの色相。電荷が増える（プロトンが取れる）ごとに暖色→寒色へ推移させる。

```css
系列0（黄土）  fill #B87A16  text #8A5A0C
系列1（緑）    fill #158A6D  text #0D6A53
系列2（青）    fill #2457A6  text #1B4380
系列3（紫）    fill #6E3AA7  text #572D85
系列4（マゼンタ）fill #A82A6A  text #831F52
系列5（深緑）  fill #3B6E1E  text #2A5215
```
fill＝グラフの線・帯グラフ・スウォッチ／text＝同系統の濃い版、ラベル文字用。彩度の高い原色（純粋な赤・青など）は使わない。

## タイポグラフィ

```css
font-family: "IBM Plex Sans JP", "Hiragino Sans", "Yu Gothic UI", system-ui, sans-serif;   /* 本文 */
font-family: "IBM Plex Mono", ui-monospace, SFMono-Regular, Menlo, monospace;               /* 数値・ラベル・式 */
```

- 日本語本文は IBM Plex Sans JP。彌榮の Noto Serif JP のような明朝系は使わない
- 数値・pH値・化学式の添字・座標軸目盛りは必ず等幅（IBM Plex Mono）。tabular-nums で桁を揃える
- 見出し（h1）は 22px / weight 600 / letter-spacing .01em。装飾的な大見出しにしない
- eyebrow（式名・分類ラベル）は Mono 11.5px、letter-spacing .14em、後ろに1pxの罫線を伸ばして右側を埋める

## レイアウト原則

- 最大幅 800〜820px、中央寄せ。読み物としての分布曲線に横幅を持たせすぎない
- 全要素をカード（背景 --surface、枠 1px --rule、角丸 3px）に収める。影は使わない
- カード間のマージンは 14px 固定
- 数値を扱う要素（pH表示・濃度・存在率）は右寄せ・tabular-nums。名称・記号は左寄せ
- ボタンは角丸 2px、選択中は背景 --ink・文字白で反転（塗りつぶし1色のみ、グラデーションなし）

## インタラクションの型

- グラフはSVGを直接文字列で組み立てる（Canvas・外部チャートライブラリは使わない）
- 横軸をポインターでなぞる／スライダー両対応。pointerdown〜pointermoveで追従し、離散的なクリックだけに頼らない
- カーソル位置に小さな黒チップ（--ink背景・白文字）で現在値を出す。ツールチップライブラリは使わない
- 破線（stroke-dasharray）は「注目すべき境界」専用。pKa・等電点など、計算上の特異点にのみ使う
- レスポンシブは430px基準でnarrowフラグを分岐。狭い画面ではピーク位置のインラインラベルを間引き、目盛りフォントを1段階落とす

## 意図的にやらないこと

- 影・グラデーション・角丸の効かせすぎ（フラットな面と1pxの罫線だけで階層を作る）
- 装飾的なアイコン（記号は文字とMonoフォントの数式表記で足りる）
- 彩度の高い原色、ネオン系の配色
- 明朝体・セリフ体（yASAKAブランドと混同させない）

## 再利用時の指定方法

「分布曲線シリーズのデザインで」「このデザインセットで」と言えば、このファイルの内容をそのまま適用する。彌榮ブランドの適用は明示的な指定があった場合のみ、という既存ルールと対になる運用。

## diagram型・matrix型共通規約(2026-09-18〜)

`html/organic-reaction-map.html`(diagram型)、`html/amino-acids-matrix.html`・
`html/protein-structure.html`(matrix型)は文字と化学式の羅列が中心で読み取りにくい、
という指摘を受けた。周期表と周期律(chem-periodic-trends)を最初の適用例として、
以降のdiagram型・matrix型教材すべてに以下を適用する。上記の「使いどころ」「カラートークン」
「タイポグラフィ」「レイアウト原則」はそのまま踏襲し、この章はカードの中身の見せ方だけを
追加で規定する。

### 分類ごとの色分け枠

族・グループなど「同じ仲間」をひとまとまりにする場合、背景色や枠線の色で視覚的にグループ化する。
系列カラー(黄土・緑・青・紫・マゼンタ・深緑)をそのまま分類の枠色に流用してよい。

- 枠線は2px、角丸3px。塗りは系列カラーの`fill`値を透明度8〜12%程度に落として敷く
  (例: `background: rgba(184,122,22,.08); border: 2px solid #B87A16;`)
- 枠のラベル(分類名)は枠の左上に小さく系列カラーの`text`値で置く。フォントはMono、
  eyebrowと同じ11.5px・letter-spacing .14em
- 1画面に同時に出す分類色は最大6系統まで(系列カラーの手持ち数と揃える)。7系統以上に
  分かれる場合は主要な系統だけに色を割り当て、残りは`--rule`のグレイ枠にとどめる
- 彩度の高い原色(純赤・純青・純黄)は使わない。既存ルールの「彩度の高い原色は使わない」を
  分類色にもそのまま適用する

### 状態に応じたアイコン

常温(25℃)で固体・液体・気体のいずれかを持つ対象を扱うときは、簡潔なSVGアイコンで一目で
状態を示す。写実的な描き込みはせず、線画1色(--inkまたはその対象の系列カラーのtext値)で
完結させる。

- **固体**: 皿(横長の楕円か浅い弧)の上に粉末または結晶(小さな三角形・粒の集合)
- **液体**: フラスコ(三角フラスコの輪郭)。中身の塗りは系列カラーを薄く敷いてもよい
- **気体**: 風船(涙滴形+結び目の小さな三角)
- アイコンサイズはカード内で18〜24px角。カードの右上か記号の隣に固定配置し、一覧性を崩す
  ほど大きくしない
- 状態が不明・未確認の対象にはアイコンを置かず、`?`のようなプレースホルダーも使わない
  (根拠のない値を作らない、という既存の完了条件と同じ扱い)

### ホバー/タップで詳細値を表示

一覧性を保つため、カード自体には最小限の情報(記号・名前・代表的な1つの値)だけを載せる。
詳細数値はホバー(タッチデバイスではタップ)でポップアップまたはツールチップに表示する。

- ツールチップライブラリは使わない(既存ルールを継承)。カーソル位置またはカードの上に
  --ink背景・白文字の小さなチップを出す実装で統一する
- タッチデバイスでは1回目のタップで詳細を開き、カード外(または同じカード)を再タップで
  閉じる。ホバーとタップの両方に同じ内容を出し、片方だけの情報にしない
- 詳細ポップアップの中身は数値+単位+(必要なら)出典・confidenceの短い注記に絞る。
  文章による解説はポップアップの外(カード下の`.text`カードなど)に置く

### 語呂合わせ・視覚的な色のバッジ

語呂合わせや、炎色反応の色のような「見た目の色」がある場合は、小さなバッジや色スウォッチを
添える。

- 語呂合わせバッジ: カード内に小さく1行、Mono以外の本文フォントで可(語呂は日本語の語感が
  本質のため)。既存のeyebrow罫線とは別枠にする
- 色スウォッチ(炎色反応など): 8〜10px角の小さな正方形か円に、実際の色をそのまま塗る。
  これは分類色や系列カラーの制約(彩度を落とした顔料寄り)を受けない例外
  ―― 炎色反応の色そのものが教材内容であるため、観察される色に忠実な塗りを使ってよい
- 該当しない対象にはバッジ自体を置かない(空欄・ダッシュ「―」で埋めない)
