# 分布曲線シリーズ デザインセット

acid-base-distribution.html（リン酸・炭酸・24系統合版）で使用したデザイントークン一式。
yASAKAブランドガイドライン（ネイビー×クリーム、Noto Serif JP＋Cormorant）とは別系統。
理系の資料・データ可視化・インタラクティブ教材で再利用することを想定。

---

## 使いどころ

- 化学・物理・生物などの数値データを扱うインタラクティブ教材
- 存在率／濃度／pHのような連続量をグラフとテーブルで並べて見せる資料
- 「静かな実験ノート」のトーン。彌榮ブランドを明示的に指定されない限り、こちらがデフォルト

## カラートークン

```css
--ink:        #16232B;  /* 本文・見出し */
--muted:      #5E6E76;  /* 補助テキスト・ラベル */
--paper:      #EDF1EF;  /* ページ背景（薄いグレイグリーン） */
--surface:    #FFFFFF;  /* カード背景 */
--rule:       #D6DDDA;  /* 罫線・枠線 */
--rule-soft:  #E8EDEB;  /* グリッド線・表の区切り */
```

### 系列カラー（電荷段階ごと）
彩度を落とした顔料寄りの色相。電荷が増える（プロトンが取れる）ごとに暖色→寒色へ推移させる。

```css
系列0（黄土）  fill #B87A16  text #8A5A0C
系列1（緑）    fill #158A6D  text #0D6A53
系列2（青）    fill #2457A6  text #1B4380
系列3（紫）    fill #6E3AA7  text #572D85
系列4（マゼンタ）fill #A82A6A  text #831F52
系列5（深緑）  fill #3B6E1E  text #2A5215
```
fill＝グラフの線・帯グラフ・スウォッチ／text＝同系統の濃い版、ラベル文字用。彩度の高い原色（純粋な赤・青など）は使わない。

## タイポグラフィ

```css
font-family: "IBM Plex Sans JP", "Hiragino Sans", "Yu Gothic UI", system-ui, sans-serif;   /* 本文 */
font-family: "IBM Plex Mono", ui-monospace, SFMono-Regular, Menlo, monospace;               /* 数値・ラベル・式 */
```

- 日本語本文は IBM Plex Sans JP。彌榮の Noto Serif JP のような明朝系は使わない
- 数値・pH値・化学式の添字・座標軸目盛りは必ず等幅（IBM Plex Mono）。tabular-nums で桁を揃える
- 見出し（h1）は 22px / weight 600 / letter-spacing .01em。装飾的な大見出しにしない
- eyebrow（式名・分類ラベル）は Mono 11.5px、letter-spacing .14em、後ろに1pxの罫線を伸ばして右側を埋める

## レイアウト原則

- 最大幅 800〜820px、中央寄せ。読み物としての分布曲線に横幅を持たせすぎない
- 全要素をカード（背景 --surface、枠 1px --rule、角丸 3px）に収める。影は使わない
- カード間のマージンは 14px 固定
- 数値を扱う要素（pH表示・濃度・存在率）は右寄せ・tabular-nums。名称・記号は左寄せ
- ボタンは角丸 2px、選択中は背景 --ink・文字白で反転（塗りつぶし1色のみ、グラデーションなし）

## インタラクションの型

- グラフはSVGを直接文字列で組み立てる（Canvas・外部チャートライブラリは使わない）
- 横軸をポインターでなぞる／スライダー両対応。pointerdown〜pointermoveで追従し、離散的なクリックだけに頼らない
- カーソル位置に小さな黒チップ（--ink背景・白文字）で現在値を出す。ツールチップライブラリは使わない
- 破線（stroke-dasharray）は「注目すべき境界」専用。pKa・等電点など、計算上の特異点にのみ使う
- レスポンシブは430px基準でnarrowフラグを分岐。狭い画面ではピーク位置のインラインラベルを間引き、目盛りフォントを1段階落とす

## 意図的にやらないこと

- 影・グラデーション・角丸の効かせすぎ（フラットな面と1pxの罫線だけで階層を作る）
- 装飾的なアイコン（記号は文字とMonoフォントの数式表記で足りる）
- 彩度の高い原色、ネオン系の配色
- 明朝体・セリフ体（yASAKAブランドと混同させない）

## 再利用時の指定方法

「分布曲線シリーズのデザインで」「このデザインセットで」と言えば、このファイルの内容をそのまま適用する。彌榮ブランドの適用は明示的な指定があった場合のみ、という既存ルールと対になる運用。
