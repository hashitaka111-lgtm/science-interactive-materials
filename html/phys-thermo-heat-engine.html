THERMODYNAMICS

熱機関とp-Vサイクル

1本目(熱力学第一法則とモル比熱)では、定積・定圧・断熱という3つの変化それぞれについて、同じ始点から同じ終端温度に達するときのQ・W・ΔUの内訳を個別に求めた。ここではそのうち定積変化と定圧変化の2つを組み合わせ、出発点にちょうど戻ってくる一連の変化 ― サイクル ― を作る。1本目で確立した計算(定積変化はW=0、定圧変化はW=−pΔV、ΔU=nCvΔT)をそのまま4つの行程に順番に当てはめ、行程ごとのQ・Wを積み上げると、サイクル全体で気体がした正味の仕事と、それを得るのにどれだけの熱が必要だったか(熱効率)が見えてくる。

扱うのは高校物理の定番、「定積昇圧 → 定圧膨張 → 定積降圧 → 定圧圧縮」の4行程からなる長方形サイクル。p-V図上でこのサイクルが囲む面積が、そのままサイクル1周で気体がした正味の仕事に等しいことを面積の塗りつぶしで確かめ、続けて熱効率 e = W / Qin を具体的な数値で計算する。カルノーサイクルの理論的な効率の上限やエントロピーには踏み込まない。

CYCLE

4つの頂点を動かしてサイクルの形を決める

長方形の4つの頂点をA・B・C・Dとする。A(Vlow, Plow) → B(Vlow, Phigh)は体積一定のまま圧力を上げる定積昇圧、B → C(Vhigh, Phigh)は圧力一定のまま体積を広げる定圧膨張、C → D(Vhigh, Plow)は体積一定のまま圧力を下げる定積降圧、D → Aは圧力一定のまま体積を戻す定圧圧縮。この順に時計回りに1周すると出発点Aに戻る。下の4つのスライダーでPlow・Phigh・Vlow・Vhighを動かすと長方形の大きさが変わる(気体は1本目と同じくn = 1.0 molに固定し、サイクルの形はこの4つの値だけで決まるようにしてある)。

BREAKDOWN

行程ごとのΔU・W・Q

符号規約は1本目と同じ、ΔU = Q + W(W = 気体が外部からされた仕事)。定積の行程(A→B, C→D)はW = 0なのでQ = ΔUがそのまま出る。定圧の行程(B→C, D→A)は1本目と同じW = −pΔVを使う。ΔU列は1周ぶん合計するとちょうど0になる ― 内部エネルギーは温度だけで決まる状態量なので、出発点に戻れば必ず変化なしになるため。

EFFICIENCY

熱効率 e = W / Qin

記号をタップすると説明が出る。4行程のうちA→B(定積昇圧)とB→C(定圧膨張)はQ>0(気体が熱を吸収する)、C→D(定積降圧)とD→A(定圧圧縮)はQ<0(気体が熱を放出する)。高温側から吸収した熱の合計をQin、サイクル1周でした正味の仕事をW(= p-V図で塗った長方形の面積)とすると、熱効率はe = W / Qin。

NOTES

使った定数

取り違えやすいところ

  • Qinは「Q > 0の行程だけ」を足したもので、4行程すべてのQを単純に合計したものではない。4行程すべてを合計するとQab+Qbc+Qcd+Qda = W(正味の仕事)になる(ΔUの合計が0だから)。
  • Wはp-V図の面積(Vhigh−Vlow)×(Phigh−Plow)として直接読み取れるが、Qinはこの面積からは読み取れない。A→BとB→Cそれぞれの数値を計算して足す必要がある。
  • 熱効率eは0〜1(0〜100%)の範囲に必ず収まる。W > Qinになることはない(それではエネルギー保存則に反する)。
  • このサイクルは時計回り(Vlowで昇圧 → 高圧側で膨張 → Vhighで降圧 → 低圧側で圧縮)なので正味の仕事は正になる。反時計回りに同じ4頂点を回ると符号がすべて逆転し、外部から正味の仕事をされて熱を低温側から高温側へ汲み上げる(冷凍機・ヒートポンプ)側の動きになるが、この教材では扱わない。
  • ΔU = nCvΔTは定積の行程だけでなく定圧の行程でも成り立つ(理想気体の内部エネルギーは温度だけで決まるため)。Q = nCpΔTになるのは定圧の行程だけで、これはΔUではなくQの式であることに注意。
  • 断熱変化はこのサイクルには含めていない(定積・定圧だけの長方形サイクル)。カルノーサイクルの効率上限1−T2/T1やエントロピーは高校物理の範囲外なので、この教材では扱わない。
