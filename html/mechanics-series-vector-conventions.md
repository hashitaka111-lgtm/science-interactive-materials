# 力学シリーズ(phys-*-motion系) ベクトル表示の共通ルール

物理第4シリーズ(落体・放物運動/剛体のつり合い/運動量と力積/円運動/万有引力)の5本で、
毎回同じ議論を繰り返さないための取り決め。`scripts/vector-diagram-engine.mjs` を
共有する5本すべてに適用する。`distribution-series-design-system.md`(色・タイポ等の
本則)を補足する位置づけで、矛盾する場合はこちらを優先する。

## 合成ベクトル(合力・速度の合成など)の表示

- 複数の成分を1本にまとめた矢印(合力、速度の合成、等)は**固定の色**(系列カラー
  c0〜c5から1色を「合成」役として割り当てる)+**ON/OFFトグル**で表示・非表示を
  切り替える。
- **破線は使わない。** `distribution-series-design-system.md` の「破線はpKa・等電点
  など計算上の特異点にのみ使う」という規約と衝突するため、合成ベクトルを実線・
  区別しやすい色の組み合わせだけで表現する。
- 「合力」という言葉が literal に当てはまらない教材(例: 落体・放物運動の
  水平・鉛直速度成分の合成)でも、同じ仕組み(固定色+トグル)を「複数成分を
  1本にまとめて見せる矢印」全般に適用する。

## 単位の異なる量を同じ物差しで描かない

- `computeScale(magnitudes, maxPx)` は**同じ単位のグループごと**に独立して呼ぶ。
  速度系(m/s)と力系(N)を混ぜて1回のcomputeScaleに渡さない。
- 画面に速度と力を同時に出す場合、両者のpxPerUnitは別々の値になる。矢印の長さを
  見た目だけで比較させない(必要なら数値ラベルを併記する)。

## 実数値を導入しない力の扱い

- 質量パラメータを教材に持ち込まない(高校物理の範囲を超える/教材の主眼から外れる)
  場合、その力(例: 落体・放物運動における重力)は実数値のcomputeScaleに乗せず、
  **固定の参照長(px)**で描画する。
- 参照長で描いた矢印は、向きだけが正しく大きさは模式的であることを凡例か
  ツールチップで明記する。速度など実数値スケールの矢印と並べて見た目の長さを
  比較できるかのように見せない(色を系列カラーではなく `var(--muted)` にする、
  ラベルに「模式的」と明記する、など)。

## ラベルの重なりチェックは軸目盛りラベルも対象に含める

- ベクトルラベルの重なり確認は、他のベクトルラベル同士だけでなく、y軸・x軸の
  目盛りラベルとの重なりも必ず確認対象に含める。物体の発射点・移動範囲が軸の
  目盛り描画域(グラフ左端・下端の余白)に近い教材では、矢印の向きに沿って
  ラベルを配置すると目盛りの数字に重なって読めなくなることがある
  (phys-projectile-motionで実際に発生: 斜方投射のデフォルト値で重力ラベルが
  y軸目盛り「10」に重なった)。

## vector-diagram-engine.mjs の扱い

- `projection-engine.mjs` は import しない。両エンジンを同じ教材(4本目の円錐振り子)
  に埋め込む場合に、関数名の衝突・import解決の失敗を避けるため。
- ワールド座標→画面px座標のスケール・原点決定(viewportへのfit)は
  `vector-diagram-engine.mjs` の担当外。各教材のステージ形状(縦長/横長になりやすい
  かなど)に依存するため、教材ごとのコードで実装する。
