SUPERPOSITION OF WAVES

波の重ね合わせインタラクティブ

波を2本用意して足すだけで、うなりも定常波も出てくる。違うのは位相差が時間で動くか、場所で固定されるか、それだけ。反射端の扱い、弦の固有振動、気柱の共鳴まで同じ足し算でつながる。

WAVE FORM

まず記号の場所を確かめる。式の中の文字に触れると、グラフのどこを指しているかが光る。

上は「ある瞬間に写真を撮った形」、下は「ある1点をずっと見ていた記録」。どちらも正弦波の形をしているせいで混同されるが、横軸が違う。上の周期が波長 λ、下の周期が時間の周期 T。

BEATS

観測点を1つ決めて、そこの変位を時間で追う。同じ向きに進む2つの波の振動数がわずかに違うと、強くなったり弱くなったりを繰り返す。

音叉で考えるとき

440 Hz の音叉と、振動数の分からない音叉を鳴らして毎秒3回のうなりが聞こえたなら、相手は 437 Hz か 443 Hz。片方におもりを少し付けると振動数が下がるので、うなりが速くなったなら相手は 437 Hz、遅くなったなら 443 Hz。これで一意に決まる。

STANDING WAVE

向きを逆にすると、包絡線が動かなくなる。腹はずっと腹、節はずっと節。薄い線は1周期を9等分した瞬間の形で、どれも同じ点を通っているのが分かる。

y (x, t) · 3D

合成波を、場所と時間の2つの軸に広げた面として描く。ドラッグで視点が回る。真上から見たときの縞の傾きが 1/v で、定常波では縞が縦になって節の位置に線が立つ。

STRING MODES

両端を固定した弦では、行きの波と帰りの波が重なって定常波になる。両端が節になる波長だけが生き残る。実際の振動数は数百 Hz なので、見えるようにゆっくり再生している。

はじいた弦の形

弦を1点でつまんで放すと、三角形の初期形が固有振動に分解される。どの倍音がどれだけ混ざるかは、つまむ位置で決まる。

AIR COLUMN

気柱でも起きていることは弦と同じ。違うのは端の条件で、閉じた端は空気が動けないので変位の節、開いた端は自由に動けるので変位の腹になる。

表示

共鳴実験から開口端補正を出す

ガラス管の水面を下げていくと、1回目の共鳴が長さ L1、2回目が L2 で起きる。L1+Δ = λ/4、L2+Δ = 3λ/4 なので、引き算すると Δ が消えて λ = 2(L2−L1)。補正は Δ = (L2 − 3L1)/2 で求まる。Δ を測るには2回共鳴させるしかない、というのがこの実験の要点。

DERIVATION

波の式の出どころ

原点にある媒質が y = A sin(2πt/T + φ) で揺れているとする。この揺れが速さ v で右へ伝わるなら、位置 x に情報が届くのは x/v だけ後になる。だから x での揺れは、原点の「x/v 秒前の揺れ」をそのまま真似する。

DELAY
y(x,t) = A sin(2π(t − x/v)/T + φ)
λ = vT
y = A sin{2π(t/T − x/λ) + φ}　　左向きなら x の符号が反転する
k, ω
k = 2π/λ、ω = 2π/T　→　y = A sin(ωt − kx + φ)

t/T と x/λ が引き算で並んでいる形がすべて。t が T 増えても、x が λ 増えても位相は 2π 動くだけなので同じ状態に戻る。時間と空間で周期が別々にあるのはこのため。

足し算を1本にまとめる

媒質の応答が線形なら、2つの解の和も解になる。合成波はただの足し算で、この先の話は全部そこから出る。y = A1 sinθ1 + A2 sinθ2 を、平均 θ̄ = (θ1+θ2)/2 と半差 δ = (θ1−θ2)/2 で書き直す。

EXPAND
y = (A1+A2) cosδ · sinθ̄ + (A1−A2) sinδ · cosθ̄
AMPLITUDE
y = R sin(θ̄ + χ)、　R = √(A12 + A22 + 2A1A2 cosΔθ)、　Δθ = θ1 − θ2

R が包絡線。A1 = A2 = A なら R = 2A|cos(Δθ/2)| に戻って教科書の形になる。近似はどこにも入っていないので、振幅が違っても振動数が違っても、そのまま使える。

PHASE GAP
Δθ = (ω1−ω2)t − (s1k1 − s2k2)x + (φ1−φ2)　　s は進行方向（+1 か −1）

うなりと定常波の分かれ目はここにしかない。同じ向きで振動数だけ違えば Δθ は t にほぼ比例して、強弱が時間で入れ替わる。逆向きで振動数が同じなら第1項が消えて Δθ は x だけの関数になり、強弱が場所に貼りつく。包絡線が動く速さは u = Δω/Δk で、前者では u = v、後者では u = 0。

うなりの振動数が差になる理由

Δθ は毎秒 Δω = 2πΔf だけ進む。R は Δθ について周期 2π だから、R が元に戻るのに 1/Δf 秒かかる。強弱の周期がそのまま 1/Δf なので、うなりは毎秒 |f1−f2| 回。

ここでよく間違えるのが 2A cos(πΔf·t) の形。cos そのものの振動数は Δf/2 で、差の半分に見えてしまう。しかし耳が拾うのは絶対値のほうで、|cos| は周期が半分になる。R = √(…) の形で書いておけば絶対値を取り忘れる余地がない。

A1 ≠ A2 のときは R の最小値が |A1−A2| になって、音は完全には消えない。変調の深さは小さいほうの振幅を大きいほうで割った値。うなりが「聞こえにくい」ときはたいていこれが原因。

定常波の節と腹

s1 = +1、s2 = −1、k1 = k2 = k とすると Δθ = −2kx + (φ1−φ2)。

NODE
cosΔθ = −1　→　x = (φ1−φ2 − π − 2πm)/(2k)　　R = |A1−A2|
ANTINODE
cosΔθ = +1　→　x = (φ1−φ2 − 2πm)/(2k)　　R = A1+A2

隣り合う節の間隔は π/k = λ/2、節と隣の腹は λ/4。振幅がそろっているときだけ、時間と場所がきれいに分離する。

A₁ = A₂
y = 2A cos(kx − Δφ/2) · sin(ωt + (φ1+φ2)/2)

場所で決まる振幅と、全点共通の時間変化に完全に割れる。どの点も同じタイミングで最大になり、山が横に動くことはない。振幅がずれていると y = 2A2cosδ·sinθ̄ + (A1−A2) sinθ1 と分解でき、定常波に進行波が乗った形になる。節が0にならないのはこの残りのせい。定在波比 (A1+A2)/|A1−A2| がどれだけ定常波に近いかの指標。

固定端と自由端

x = L に端があり、右向きの波 yi = A sin(ωt − kx) が入射する。反射波を yr = A′ sin(ωt + kx + ψ) と置いて、端の条件から A′ と ψ を決める。

FIXED
y(L,t) = 0 が常に成り立つ　→　A′ = A、ψ = π − 2kL
FREE
∂y/∂x = 0（端に横向きの力がかからない）　→　A′ = A、ψ = −2kL

固定端だけ π が残る。これが位相の反転。端は必ず節になる。自由端では π が付かず、端が腹になる。節の位置は固定端で x = L − mλ/2、自由端で x = L − λ/4 − mλ/2。ちょうど λ/4 だけずれる。

エネルギーの向きで考えると納得しやすい。固定端では壁が弦を引き止めるので、弦は壁から逆向きの力を受ける。自由端では止めるものがないので、行き過ぎた分がそのまま戻ってくる。

波動方程式を差分で解く

反射のカードだけは、上の式を使わずに元の方程式を直接解いている。∂2y/∂t2 = v2∂2y/∂x2 を中心差分に置き換えると次の形になる。

SCHEME
yin+1 = 2yin − yin−1 + C2(yi+1n − 2yin + yi−1n)、　C = vΔt/Δx
C = 1
yin+1 = yi+1n + yi−1n − yin−1

C を 1 に取ると 2yin が消えて、この形になる。1次元の波動方程式に限れば、これは丸め誤差の範囲で厳密。y = f(x−vt) を代入すると Δx = vΔt から両辺が一致する。数値的な分散もない。だから「計算誤差で反転して見えている」という逃げ道がない。

  • 固定端は yN = 0 を毎ステップ課すだけ。
  • 自由端は仮想点 yN+1 = yN−1 を置いて、yNn+1 = 2yN−1n − yNn−1。
  • 左端は吸収境界。C = 1 なら y0n+1 = y1n が左向きの波を完全に飲み込む。戻ってきた波が再反射しないので、右端の反射だけを見られる。
  • 入射波は全体場と散乱場を切り分ける方式で流し込んでいる。境界より右は「入射波+反射波」、左は「反射波だけ」を保持するので、反射波を単独で取り出して描ける。

弦の固有振動

両端が固定なら両端が節。長さ L に節が両端で入る条件から L = nλ/2 が出る。

STRING
λn = 2L/n、　fn = nv/(2L) = (n/2L)√(S/ρ)　　S は張力、ρ は線密度

倍音が整数比できれいに並ぶのは、v が振動数によらない（分散がない）から。実際の弦には曲げ剛性があるので高次ほどわずかに高くなる。ピアノの調律で問題になるのがこのずれ。

PLUCK
位置 pL を高さ h でつまむと　an = 2h/(n2π2p(1−p)) · sin(nπp)

三角形の初期形をフーリエ正弦級数に分解した係数。1/n2 で減るので高次はすぐ小さくなる。真ん中でつまむと sin(nπ/2) が偶数の n で 0 になり、偶数倍音が全部消える。弦長の 1/5 の位置で弾けば5倍音が消える、というのも同じ式から出る。

気柱

開いた端は空気が自由に動けるので変位の腹、閉じた端は動けないので変位の節。圧力はちょうど逆で、開口端が圧力の節になる。閉管の閉じた端では空気が動けない代わりに圧力が最も大きく振れる。

OPEN
Le = nλ/2　→　fn = nv/(2Le)、Le = L + 2Δ　　整数倍音がすべて出る
CLOSED
Le = (2m−1)λ/4　→　f = (2m−1)v/(4Le)、Le = L + Δ　　奇数倍音だけ

同じ長さなら閉管の基本音は開管の半分。クラリネットが同じ管長のフルートより1オクターブ低いのはこの違い。

音速の温度依存

断熱変化する理想気体では v = √(γRT/M)。空気なら γ = 1.4、M = 28.9647 g/mol で、0°C は 331.3 m/s になる。教科書の v = 331.5 + 0.6t は、これを t = 0 のまわりで1次まで展開したもの。

EXPANSION
v = v0√(1 + t/273.15) ≒ v0(1 + t/546.3)　→　係数は 331.3/546.3 = 0.606

0.6 はその丸め。30°C でも厳密値との差は 0.1% 程度しかないので、実用上は気にしなくていい。それより開口端補正のほうが桁違いに効く。

NOTES

どの近似がどこで効くか

使った定数

開口端補正の係数は、フランジのない円管に対する Levine–Schwinger の理論値 0.6133a を既定にした。日本の教科書でよく見る 0.6a はこの丸め、無限に広い板に開口したとき（フランジ付き）は 8/(3π) = 0.8216a になる。管の口がどうなっているかで実測値が変わるので、実験値と合わないときはまずここを疑う。切り替えて差を見られるようにしてある。

音速の基準値は断熱式から出した 331.3 m/s を既定にした。0°C 乾燥空気の実測は 331.29 m/s（Wong 1986）で、断熱式とほぼ一致する。教科書の 331.5 は測定の古い値に由来する丸めで、断熱式より 0.05% ほど高い。気柱の計算では、この 0.05% より開口端補正の数% のほうがはるかに大きい。

弦の既定値は長さ 0.65 m、張力 73 N、線密度 0.40 g/m にしてある。ギターの1弦（0.010インチのプレーン弦）に近い値で、基本振動が E4 あたりに来る。

取り違えやすいところ

  • y-x グラフと y-t グラフを混ぜない。横軸が距離なら山の間隔は λ、時間なら T。問題文が「ある瞬間の」と言っていたら前者、「ある点の」と言っていたら後者。
  • うなりの回数は差の絶対値で、差の半分ではない。2A cos の cos だけ見ると半分に見えるので注意。
  • 定常波でも媒質は動いている。動かないのは節の点だけで、腹は最も激しく動く。「定常」なのは波形が横に進まないという意味。
  • 定常波にはエネルギーの流れがない。左右に同じだけ流れていて差し引きゼロになる。
  • 固定端は変位の節、自由端は変位の腹。気柱では開口端が変位の腹で、圧力の節。変位と圧力を混ぜると全部逆になる。
  • 閉管に偶数倍音はない。基本振動の3倍が第2の共鳴で、これを「2倍振動」と呼ぶ流儀もあるので、問題文がどちらの数え方をしているか確認する。
  • 開口端補正は開いている端の数だけ効く。開管は 2Δ、閉管は Δ。
  • 波が反射しても振動数は変わらない。変わるのは進む向きと、固定端なら位相。媒質が同じなら波長も速さもそのまま。
  • 2つの波が重なっている間も、それぞれの波は相手を気にせず進み続ける。すれ違ったあとは元の形に戻る。重ね合わせは「その瞬間の変位を足す」だけの話。
