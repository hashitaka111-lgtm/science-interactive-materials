BUFFER SOLUTIONS · 03

緩衝溶液
ヘンダーソン・ハッセルバルヒ、緩衝能、滴定曲線上での位置

滴定曲線を pH の側から閉じた形で解き、緩衝能を Cb の中心差分で求めます。HH 式との差、水そのものの緩衝能、当量点でのテーマ2との接続を同じ画面で確認できます。医学部受験向け。

EXACT FORMULATION

厳密式

弱酸を全濃度 C_T で溶かし、強塩基を Cb 加えた系。テーマ2の塩の式に Cb の項が付いただけです。

質量収支 C_T = [HA] + [A⁻] 電荷収支 Cb + [H⁺] = [A⁻] + [OH⁻] g(h) = Cb + h − Kw/h − C_T·Ka/(Ka + h) = 0

HH 式が捨てているもの

Ka = h[A⁻]/[HA] は定義なので、対数をとった形には近似が入っていません。近似はその先、[A⁻] を Cb に、[HA] を Ca に置き換えるところにあります。

[A⁻] = Cb + h − Kw/h [HA] = Ca − h + Kw/h pH = pKa + log( (Cb + h − Kw/h) / (Ca − h + Kw/h) )

補正項 (h − Kw/h) は、酸が自分で電離した分と塩基が加水分解した分の差。Ca と Cb の両方がこれより十分大きければ HH 式が使えます。pKa が中性から遠い緩衝液ほど早く壊れるのは、h が大きいぶん補正が効き始めるのが早いためです。

滴定曲線は逆向きに解く

滴下量から pH を求めると毎回二分法が要りますが、逆は閉じた形で書けます。

f = z̄(h) + (Kw/h − h) / C_T f は滴定率（酸 1 mol あたりの塩基の当量数）

f は h について単調なので、pH を細かく振って (f, pH) を並べればそれが滴定曲線そのもの。pH 側を等間隔にサンプルするので、当量点の急峻な立ち上がりも自然に細かく描けます。

緩衝能

β = dCb/dpH Cb = C_T·z̄(h) + Kw/h − h β = 2.303 ( Kw/h + h + C_T·Var(j) ) Var(j) は結合プロトン数の分散。1価なら Var = α₀·α₁ = Ka·h/(Ka + h)² h = Ka で最大 1/4 をとるので β_max = 2.303·C_T/4 = 0.576·C_T

分散という形にしておくと多価がそのまま乗ります。クエン酸のように pKa が 1.5 ずつしか離れていない系では隣の山と重なり、ピークが単独の酸より 18% 高くなる。緩衝剤としてクエン酸が重宝される理由がここに出ています。

このページでは定義どおり Cb の中心差分（ΔpH = 0.004）で計算しています。上の解析式とは小数第6位まで一致します。

滴定曲線上の5つの位置

f = 0 弱酸単独 → テーマ1 0 < f < 1 緩衝域 → HH 式 f = 0.5 半当量点 pH = pKa、緩衝能が最大 f = 1 当量点 pH = 7 + ½pKa + ½log C_T → テーマ2 f > 1 強塩基の過剰 pH = 14 + log((f−1)·C_T)

酢酸 0.1 mol/L の当量点を厳密に解くと 8.879 で、テーマ2で 0.1 mol/L の酢酸ナトリウムを解いた値と一致します。3つのテーマは1本の滴定曲線の別々の点を見ていただけ、というのがこのシリーズの落としどころです。

SELECT SYSTEM

f は酸1 mol あたりに加えた強塩基の当量数。希釈は考えず、体積一定で塩基だけを加えるモデルです。アンモニウム系は f = 1 が 0.1 mol/L のアンモニア水にあたるので、アンモニアを塩酸で滴定する場合は f を 1 から 0 へ動かして読んでください。

TITRATION CURVE

滴定曲線

太い線が厳密解、細い線が HH 式。破線の縦線は半当量点と当量点、横線は pKa。3つのグラフはすべて連動します。

BUFFER CAPACITY

緩衝能

太い線が全体の β、細い線が水だけの寄与 2.303(h + Kw/h)。細い線より上に出ている高さが緩衝剤の働きです。両端で細い線が跳ね上がり、緩衝剤の山を追い越すところが見どころ。

WHICH BUFFER FOR WHICH pH

緩衝剤の使い分け

縦軸は β を 2.303·C_T で割った規格化緩衝能で、濃度によりません。1価の酸なら必ず 0.25 が上限。クエン酸だけ山が重なって 0.29 まで届きます。

WHERE THE APPROXIMATION BREAKS

近似が壊れる4か所

薄い緩衝液と、pKa が中性から離れた緩衝液が弱い。0.01 mol/L の酢酸緩衝液のピークが 0.0058 なのに対し、水そのものの緩衝能は pH 2 でも pH 12 でも 0.023 あります。強酸性・強塩基性の領域に緩衝剤を入れてもほとんど意味がない、というのがこの表の帰結です。

PLASMA CARBONATE SYSTEM

血漿の炭酸緩衝系

pH 7.40 で HCO₃⁻ と溶存 CO₂ の比が 20:1。見かけの pKa′ = 6.1 を使って 6.1 + log 20 = 7.40 になります。この 6.1 は 37 ℃・生理的イオン強度のもとで pCO₂ から換算した値で、このページが使っている 25 ℃ 純水の pKa₁ = 6.35 とは別の数字です。どちらを使うかは問題文の指定に従ってください。

比が 20:1 なら f(1−f) = 0.045 で、緩衝能はピークの 18% しかありません。それでも血漿が pH を保てるのは、CO₂ を呼吸で系外へ捨てられる開放系だから。試験管の中の緩衝液とは別の原理が効いています。
