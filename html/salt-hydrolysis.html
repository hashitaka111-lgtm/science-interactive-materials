SALT HYDROLYSIS · 02

塩の加水分解
組成からの液性判定と加水分解定数

18種類の塩を1本の電荷収支式で扱い、二分法で厳密に解きます。高校の5類型の近似式と並べて、どこまで使えてどこから外れるかを表示します。医学部受験向け。

EXACT FORMULATION

加水分解は共役塩基の電離そのもの

CH₃COONa を溶かすことと、Kb = Kw/Ka の弱塩基を溶かすことは式の上で同一です。テーマ1のソルバがそのまま使える。本当に新しいのは、陽イオンと陰イオンが両方加水分解する弱酸弱塩基塩と、多価酸の中間状態である酸性塩の2つだけ。

一般化した電荷収支

塩を3つの部品に分解すると、18種類すべてが1本の式に乗ります。

傍観イオン 加水分解しないもの。正味電荷を spec とする 陰イオン系 親酸 HnA の Ka 配列。平均電荷 −z̄a(h) 陽イオン系 陽イオン BHm^m⁺ の Ka 配列。平均電荷 +z̄c(h) g(h) = h − Kw/h + spec·C + nc·C·z̄c(h) − na·C·z̄a(h) = 0

z̄a は h とともに減り、z̄c は増える。h も −Kw/h も増える。全項が同じ向きなので g は狭義単調増加で、二分法が一意解に必ず収束します。NaCl なら陰陽どちらの系も持たず spec = 0 で g = h − Kw/h、pH 7 が自動的に出る。Na₂CO₃ なら spec = +2、(NH₄)₂SO₄ なら陽イオン系を2倍にして硫酸系を1つ。場合分けは不要です。

プロトン収支

電荷収支から物質収支を引くと、手計算で使える形が残ります。

CH₃COONa [CH₃COOH] = [OH⁻] − [H⁺] NaHCO₃ [H₂CO₃] + [H⁺] = [CO₃²⁻] + [OH⁻]

加水分解でできた酢酸の分だけ OH⁻ が余る。HCO₃⁻ がプロトンをもらった分と手放した分が水の側で釣り合う。両性塩の計算はこの1行から始めるのが最短です。

加水分解定数と加水分解度

A⁻ + H₂O ⇌ HA + OH⁻ Kh = [HA][OH⁻]/[A⁻] = Kw / Ka BH⁺ ⇌ B + H⁺ Kh = [B][H⁺]/[BH⁺] = Kw / Kb Kh = C·β²/(1 − β) ≈ C·β² β = √(Kh / C)

右の式はオストワルドの希釈律で、テーマ1の Ka を Kw/Ka に差し替えただけ。だから加水分解度も希釈すると増えるし、崩れ方も同じ形になります。

5類型の近似式

強酸＋強塩基 NaCl pH = 7 弱酸＋強塩基 CH₃COONa pH = 7 + ½pKa + ½log C 強酸＋弱塩基 NH₄Cl pH = 7 − ½pKb − ½log C 弱酸＋弱塩基 CH₃COONH₄ pH = ½(pKa_A + pKa_B) 酸性塩（両性） NaHCO₃ pH = ½(pKa₁ + pKa₂)

下2つが濃度に依存しない理由は別物です。弱弱塩は [BH⁺] ≈ [A⁻] という対称性から来ていて、加水分解がどれだけ進んでも比が保たれる。NH₄CN は 0.1 mol/L で加水分解度が 0.49 に達しますが、それでも ½(pKa_A + pKa_B) = 9.23 が小数第3位まで合います。β が大きいことと近似が壊れることは別問題。

両性塩のほうはプロトン収支から出ます。より正確な形は次のとおりで、C ≫ Ka₁ かつ Ka₂C ≫ Kw のときに √(Ka₁Ka₂) へ落ちる。

[H⁺] = √( Ka₁(Ka₂·C + Kw) / (Ka₁ + C) )

Na₂HPO₄ では Ka₃·C = 4.5×10⁻¹⁴ に対して Kw = 1.0×10⁻¹⁴ なので、Kw の項が2割近く効きます。落とすとずれる。
