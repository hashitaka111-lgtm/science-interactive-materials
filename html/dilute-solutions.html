Raoult / colligative properties / π = cRT

希薄溶液と束一的性質

蒸気圧降下、沸点上昇、凝固点降下、浸透圧。この4つは別々の現象ではなく、溶媒の蒸気圧が下がるという1つの事実の見え方の違いです。溶質の種類が結果に効かないことを数値で確かめ、浸透圧が PV=nRT と同じ式になる理由まで追います。

前半の温度は K と ℃ を併記。圧力は 10⁵ Pa（1 atm = 1.013×10⁵ Pa = 760 mmHg）。気体定数は R = 8.314 J·mol⁻¹·K⁻¹ = 0.08206 L·atm·mol⁻¹·K⁻¹。

00 / 条件

溶媒と溶質を決める

ここで選んだ条件が、下の 01 から 03 と 06 に反映されます。質量指定に切り替えると、同じ重さを溶かしたときに溶質ごとで結果がどれだけ変わるかを比べられます。

01 / 蒸気圧降下

ラウールの法則は溶質のモル分率だけを見る

P = x_A · P°　　ΔP = P° − P = x_B · P°　　（x_B は溶質粒子のモル分率）

直線の傾きは溶媒の蒸気圧そのもの。溶質が砂糖でも食塩でも、粒子のモル分率が同じなら同じ点に乗ります。食塩が砂糖の2倍下げるのは、1個が2個に分かれてモル分率が2倍になるからで、イオンだから強いわけではありません。

02 / 相図でつながる

沸点上昇と凝固点降下は同じ1本の曲線から出る

溶液の蒸気圧曲線は、純溶媒の曲線を x_A 倍に押し下げただけのものです。この1本を下げると、1気圧の水平線との交点は右へ動き（沸点上昇）、固体の昇華曲線との交点は左へ動きます（凝固点降下）。両方が同時に起こる理由がここに見えます。

03 / まとめて計算

4つの量を一度に出す

ΔT_b = i·K_b·m　　ΔT_f = i·K_f·m　　π = i·c·RT　　ΔP = x_B·P°

下の3つは近似式（ΔT = K·m）の値です。その下に、近似を使わずに ln x_A = −(ΔH/R)(1/T − 1/T₀) を解いた厳密値を並べています。濃度を上げていくと差が開くので、どこまで近似が使えるかが見えます。

04 / 種類によらない

効くのは粒子の数だけ

横軸は溶かした量そのもの（質量モル濃度）。傾きは i·K_f なので、非電解質はすべて1本に重なり、2粒子に分かれる塩はその2倍、3粒子なら3倍の傾きになります。理論値のボタンでは 1 : 2 : 3 にきれいに揃い、実測値に切り替えると電解質だけが下にずれます。

粒子の濃度を揃えると全部同じ値になる

溶質粒子の質量モル濃度 i·m を下のスライダーの値に固定して、そこから逆算した表です。溶かす質量は数倍も違うのに、凝固点降下の値は小数点以下まで一致します。

05 / 濃度の使い分け

mol/L と mol/kg はどこで食い違うか

c = 1000·ρ·m / (1000 + m·M)　　　ρ は溶液の密度 [g·cm⁻³]

沸点や凝固点を扱う場面では体積が温度で変わってしまうため、温度に依存しない質量モル濃度を使います。浸透圧は一定温度で測るので体積基準のモル濃度でかまいません。希薄なうちは水溶液で c ≒ m ですが、濃くなると溶質の質量が分母を押し上げてずれていきます。

実際の溶液密度は濃度で変わります。0.9% 食塩水で 1.005、5% ブドウ糖液で 1.017、1 mol/kg のスクロース水溶液なら 1.12 ほど。ここでは密度をスライダーで与えて換算式そのものを見ています。

06 / 浸透圧

πV = nRT は PV = nRT と同じ式

半透膜の左に溶液、右に純溶媒を置くと、溶媒は左へ入ろうとします。それを止めるのに必要な圧力が浸透圧です。式を並べると文字まで一致します。

同じ物質量を同じ体積に入れたとき、気体の圧力と溶液の浸透圧は同じ値になります。下で確かめてください。液柱の高さは h = π/(ρg) で、わずかな濃度でも数十メートル分の水圧に相当します。

07 / 輸液と等張性

血漿と釣り合う濃度が決まっている理由

血漿の浸透圧モル濃度はおよそ 285 mOsm/kg。細胞膜を通れない粒子の数がこの値から外れると、赤血球は水を吸って膨らむか、水を奪われて縮みます。輸液を選ぶと、組成から浸透圧モル濃度を計算して血漿と比べます。

赤血球の体積は浸透圧に反比例する

細胞内の水だけが出入りし、タンパク質などが占める体積は変わりません。その分を全体の 30% として、ボイル・ファントホッフの関係 V/V₀ = 0.30 + 0.70×(285/Osm) で見積もっています。1.4 倍を超えると膜が破れて溶血します。

まとめ

持ち帰る5つ

  • 4つの束一的性質はすべてラウールの法則の言い換え。溶質の正体は式に入らず、粒子の数だけが入る。
  • K_b と K_f は溶媒の定数で、沸点・凝固点と蒸発熱・融解熱から計算できる。水で K_f が K_b の3.6倍なのは融解熱が小さいから。
  • 温度が変わる測定には質量モル濃度、一定温度で測る浸透圧にはモル濃度。
  • πV = nRT。理想気体からのずれを Z で測るのと同じように、溶液のずれは浸透係数 φ = i/ν で測る。
  • 0.9% 食塩水は計算上 308 mOsm/L だが、φ = 0.93 を掛けると 285 になり血漿と等張になる。

定数の出典。K_b・K_f・蒸発熱・融解熱・密度は CRC Handbook 系の値。教科書では水の K_b = 0.52、K_f = 1.86 と丸めて載ることが多く、本稿の 0.515 と 1.853 は同じ量の桁を1つ増やしたものです。ファントホッフ係数の実測値は 0.1 mol/kg での値で、薄めるほど理論値 ν に近づきます。相図の曲線はクラウジウス・クラペイロンの式で蒸発熱を一定とみなして描いているため、沸点から離れた低圧側では圧力の絶対値が数十パーセントずれます。交点の温度は 1% 以内で合います。
