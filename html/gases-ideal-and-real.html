PV=nRT / van der Waals / Maxwell–Boltzmann

理想気体と実在気体

PV=nRT はどこまで使えて、どこから外れるのか。ファンデルワールス式を3次方程式として数値的に解き、同じ温度・同じ圧力での体積の差を見ます。臨界点、分圧、分子の速度分布まで、グラフをなぞりながら数値で確認できます。

圧力の単位は 10⁵ Pa（1 bar、1 atm = 1.013×10⁵ Pa）。体積は 1 mol あたりの L で表示します。気体定数は R = 0.083145 L·10⁵Pa·mol⁻¹·K⁻¹ = 8.314 J·mol⁻¹·K⁻¹。

01 / 等温線

P–V 図で理想と実在を重ねる

ファンデルワールス式は、動ける体積を V−nb に狭め、壁を叩く勢いを an²/V² だけ差し引いた式です。1 mol あたりで解くと圧力は次のように書けます。

P = RT/(V − b) − a/V²　　　　（理想気体は P = RT/V）

気体を選んで温度を動かしてください。臨界温度より下ではS字のふくらみ（ループ）が出ます。ここは dP/dV > 0、つまり体積を押し縮めると圧力が下がる領域で、実在しません。実際には水平な線に置き換わり、その高さが蒸気圧、両端が液体と気体のモル体積です。

02 / 圧縮率因子

Z = PV/(nRT) のずれ方で補正の勝敗が見える

理想気体なら Z は常に 1。実在気体では、引力の補正が勝つと 1 より小さく、排除体積が勝つと 1 より大きくなります。低圧側の傾きがゼロになる温度がボイル温度 T_B = a/(Rb) で、ファンデルワールス式では T_B = (27/8)T_c。

下のグラフは、各圧力で3次方程式を解いて得た実際のモル体積から Z を計算したものです。臨界温度より低い気体では、蒸気圧のところで気体の枝から液体の枝へ飛びます。曲線が切れているのがその凝縮です。

03 / 臨界点

a と b だけで臨界定数が決まる

臨界等温線では極大と極小が重なって変曲点1つに縮退します。∂P/∂V = 0 と ∂²P/∂V² = 0 を連立すると、余計な仮定なしに3つの臨界定数が出ます。

V_c = 3b　　T_c = 8a/(27Rb)　　P_c = a/(27b²)　　Z_c = P_cV_c/(RT_c) = 3/8 = 0.375

Z_c からは a も b も消えるので、どの気体でも 0.375 になるはずです。実測は 0.23 から 0.30。ファンデルワールス式は臨界温度と臨界圧力をよく当てる一方で、臨界体積は 3b が実測より3割ほど大きく出ます。行をタップすると、その気体が上のグラフにも反映されます。

a・b・臨界定数の実測値はいずれも CRC Handbook 系の値を採用。a は 10⁵Pa·L²·mol⁻²、b は L·mol⁻¹。教科書によっては atm 基準の a（本表の値を 1.013 で割ったもの）が載っているので、単位を確認してから使ってください。

04 / 分圧とモル分率

分圧比は物質量比そのもの

混合気体でも、理想気体なら成分どうしは互いに無関心です。成分 i だけがその体積を単独で占めたときの圧力が分圧で、P_i V = n_i RT が成り立ちます。全圧で割れば

P_i / P = n_i / n = x_i　　　　P = ΣP_i（ドルトンの分圧の法則）

物質量比と体積比と分圧比が同じ数字になる、という一点だけ押さえれば計算は終わります。組成のスライダーを動かすと、モル分率と分圧が同時に変わります。

肺胞気酸素分圧（医学部志望向け）

気道に入った空気は体温で飽和水蒸気になるので、まず水蒸気分圧 47 mmHg が全圧から差し引かれます。残りに吸入気酸素濃度 FIO₂ を掛けたものが肺胞へ届く酸素で、そこから二酸化炭素と交換された分を引きます。呼吸商 R = 0.8 として

PAO₂ = (PB − 47) × FIO₂ − PaCO₂ / 0.8

05 / 速度分布

同じ温度でも、速さは1つに揃わない

3次元のマクスウェル・ボルツマン分布は、速さの2乗で増える項と指数関数で潰す項の積になっています。

f(v) = 4π(M/2πRT)^{3/2} · v² · exp(−Mv²/2RT)

山の頂点が最頻値 v_p = √(2RT/M)、重心が平均 v̄ = √(8RT/πM)、二乗平均平方根が v_rms = √(3RT/M)。比は常に √2 : √(8/π) : √3 で、温度にも分子量にもよりません。曲線の下の面積は必ず1なので、温度を上げて裾が伸びれば山は必ず低くなります。

高速側の裾の割合は数値積分（台形則、2000分割）で計算しています。温度を上げたときに増えるのは平均速度そのものより裾の分子の数で、この効き方が反応速度のアレニウス式につながります。

まとめ

持ち帰る4つ

  • ファンデルワールス式の補正は2か所だけ。体積は V−nb に狭まり、圧力は an²/V² だけ目減りする。
  • Z が1より小さければ引力が優勢、大きければ排除体積が優勢。高圧では必ず Z > 1 に転じる。
  • 臨界定数は a と b から一意に決まり、Z_c = 3/8 は気体によらない。実測が 0.23〜0.30 に散るのがこのモデルの限界。
  • 混合気体では物質量比＝体積比＝分圧比。肺胞気の計算もこの1行から出る。

次のテーマは希薄溶液です。浸透圧の π = cRT は、いま見た PV = nRT を n/V = c と書き換えただけの形をしています。溶質分子が溶媒の中を飛び回って半透膜を叩いている、という描像がそのまま重なることを、束一的性質の側から確認します。
