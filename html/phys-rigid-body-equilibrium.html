RIGID BODY EQUILIBRIUM

剛体のつり合いインタラクティブ

一端を壁にヒンジで固定した一様な棒を、もう一端の近くでロープにより支え、棒の途中の1点に外から力を加える。棒は動かず静止したままなので、棒に働く力の水平成分の合計・鉛直成分の合計・ヒンジまわりのモーメントの合計は、それぞれ常にちょうどゼロになる。この3つのつり合いの式から、ロープの張力とヒンジの反力を逆算する。

SIMULATOR

棒に加わる力を変えて、張力とヒンジの反力を見る

棒は水平に固定されている。ヒンジ(x=0)・重心(x=L/2、重力mgが下向きに働く)・外力の作用点(x=xF)・ロープの固定点(x=L)の4か所に力が働く。4本の矢印はすべて同じ物差し(N)で描いているので、長さをそのまま大きさの比として読める。

棒の長さ L =2.00 m(固定・変数化しない)

VECTORS

4本の力のつり合いから張力と反力を逆算する

棒が静止したままということは、重力mg・外力F・ロープの張力T・ヒンジの反力Rの4本を全部足すとゼロになるということ。水平成分の合計がゼロ、鉛直成分の合計がゼロという2つの式に、ヒンジまわりのモーメントの合計がゼロという式を合わせると3つの式になる。未知数はT・Rx・Ryの3つなので、過不足なく解ける。

モーメントは、4つの力がすべて棒の上(高さ0の直線上)に乗っていることを使うと簡単になる。位置x、鉛直成分Fyの力がヒンジ(原点)まわりに作るモーメントはx×Fyだけで決まり、水平成分は関与しない。図の棒の下に伸びる細い線は、この「腕の長さ」(ヒンジから力の作用線までの垂直距離、|x×sinθ|に等しい)を表す補助線で、破線は使わず淡色の実線で描いている。

外力の角度θFは、棒に沿ってロープ側を向く向きを0°とし、そこから棒の上側へ回転させた角度として測る(90°が棒に垂直、180°で向きが反転してヒンジ側を向く)。

計算した張力Tが0以下になる場合がある。ロープは押す力を出せないので、その配置では実際にはロープがたるみ、想定した「棒が静止したまま」という前提が崩れる(この場合、図では張力の矢印を描かず、注意書きを表示する)。

EQUATIONS

つり合いの式

右向きをx正、上向きをy正、反時計回りのモーメントを正とする。

水平方向のつり合い
ΣFx = 0　→　Rx + FcosθF − Tcosφ = 0
鉛直方向のつり合い
ΣFy = 0　→　Ry + FsinθF + Tsinφ − mg = 0
ヒンジまわりのモーメントのつり合い
ΣM = 0　→　−(L/2)mg + xF·FsinθF + L·Tsinφ = 0
3式を解くと
T = (mgL/2 − xFFsinθF) / (Lsinφ)
Rx = Tcosφ − FcosθF
Ry = mg − FsinθF − Tsinφ
