Polymer / 合成高分子化合物

重合度と平均分子量

合成樹脂(プラスチック)・合成繊維・合成ゴムは、どれも小さな分子(モノマー)がたくさんつながってできた巨大な分子(高分子)です。1本の鎖につながったモノマーの数を重合度nといい、高分子の平均分子量Mはこのnに比例します。モノマーのつながり方には、モノマーがそのまま次々につながる付加重合と、モノマー同士がつながるたびに水などの小さな分子が脱離する縮合重合の2種類があり、Mの求め方も少し違います。ポリエチレン・ポリ塩化ビニル・ナイロン66・PETの4物質で、この計算を確認します。

原子量はH=1.0, C=12.0, N=14.0, O=16.0, Cl=35.5(高校化学の慣例値)で統一しています。

01 / POLYMERIZATION — 付加重合と縮合重合

モノマーのつながり方は2種類ある

高分子はモノマーがn個つながってできています。このnを重合度といいます。つながり方には大きく2つの型があります。

付加重合

モノマーが持つ二重結合(C=C)が開いて、次々に直接つながる反応です。つながる際に何も脱離しないので、モノマーの原子はすべてそのまま高分子に残ります。

n CH2=CH2 → −[ CH2−CH2 ]−n (ポリエチレンの例)

縮合重合

2種類のモノマーが交互につながる反応です。1組のモノマーがつながって結合(アミド結合・エステル結合など)ができるたびに、H2Oのような小さな分子が脱離します。脱離した分だけ、高分子に残る原子は少なくなります。

n HOOC−R−COOH + n H2N−R'−NH2 → −[ CO−R−CO−NH−R'−NH ]−n + 2n H2O (ナイロン66のような例)

どちらの場合も、高分子1本の中で繰り返されている最小のまとまりを「繰り返し単位」といい、その式量に重合度nをかけたものが高分子の平均分子量Mです。

M = n × (繰り返し単位の式量)
付加重合では繰り返し単位=モノマーそのものなので、M = n × (モノマーの式量) と同じ意味になります。縮合重合では、繰り返し単位の式量が「モノマーの式量の合計から、脱離した小分子の分を引いた値」になる点が付加重合との違いです。02で実際の4物質について、この計算過程を確認します。

ポリマーを1つ選ぶと、そのモノマー(縮合重合では2種類)と、そこから繰り返し単位ができるまでの計算過程が表示されます。

03 / DEGREE OF POLYMERIZATION — nを動かしてMを見る

重合度nと平均分子量Mは比例する

繰り返し単位の式量が決まれば、あとは重合度n倍するだけでMが求まります。実際の高分子はnが数百〜数万にもなるため、下のスライダーは対数目盛りで動かせるようにしています。動かすとMがnに比例してリアルタイムに変わる様子を、数値とグラフの両方で確認できます。

04 / NOTES

この教材のまとめと、扱わなかったこと

縮合重合の脱水は、ペプチド結合の脱水縮合と同じ原理です。アミノ酸が2個つながってジペプチドになるとき、ペプチド結合が1つできるたびにH2Oが1つ脱離します(ペプチドの配列決定で扱った「n残基のペプチドの分子量 = アミノ酸の分子量の合計 − 18×(結合の数)」という計算と同じ考え方)。ナイロン66やPETでは、モノマー2つの間に結合が2か所できるため、1組あたりH2Oが2個脱離するという違いはありますが、「結合が1つできるたびにH2Oが1つ脱離する」という原理そのものは共通です。

この教材で扱っていないこと。天然ゴム(イソプレンの重合)や加硫、熱可塑性樹脂と熱硬化性樹脂の分類、フェノール樹脂のような付加縮合は、いずれもこの教材の範囲外です。ここでは「重合度nから平均分子量Mを計算する」という1点に絞りました。

  • 付加重合はモノマーがそのまま繋がる。脱離する小分子はなく、M = n × (モノマーの式量)。
  • 縮合重合はモノマー同士が繋がる際にH2Oなどの小分子が脱離する。繰り返し単位の式量は、モノマーの式量の合計から脱離した分を引いた値。
  • ナイロン66・PETは2種類のモノマーが1組ずつ縮合し、1組あたりH2Oが2個脱離する。
  • どちらの重合でも、平均分子量M = n × (繰り返し単位の式量)。nを横軸、Mを縦軸にとると直線になる。
