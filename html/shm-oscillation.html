SIMPLE HARMONIC MOTION

単振動インタラクティブ

等速円運動する点の影が単振動になる。円を指で回すと右に波が描かれ、速度と加速度も同じ影として出てくる。ばね振り子と単振り子を切り替えて、どちらも同じ式に落ちることと、sinθ≈θ が何を捨てているかを数値で確かめる。

MODEL

CIRCLE → WAVE

左の円を指やマウスで回すと、右に x-t グラフが描かれる。円周上の点の速度ベクトルと加速度ベクトルを、変位の軸に落とした影が v と a になる。

速さ
表示

HELIX / 3D

円運動を時間の方向に引き伸ばすと螺旋になる。正面から見れば円、真横から見れば正弦波。ドラッグで視点が動く。

視点
x · v · a

同じ時刻の縦線で3つがつながっている。a は x を上下反転して定数倍したもので、向きが一致することは一度もない。

PHASOR

3つの量を、同じ角速度で回る矢印として重ねる。長さは比べられないので、それぞれ見やすい長さに揃えてある。読むのは角度だけ。

sinθ ≈ θ

単振り子の周期を近似なしで解く。第一種完全楕円積分を算術幾何平均で計算し、別経路として運動方程式そのものを RK4 で積分した結果も並べる。両者が一致することが、数値が正しいことの担保になる。

振れ角 θ0

2次近似は T ≒ T0(1 + θ0²/16) を展開の途中で打ち切ったもの。30° までなら厳密値と 0.03% しか違わないのに、90° では 2.2% ずれる。近似式そのものが効く範囲も狭い。

DERIVATION

円運動の影として

半径 A の円周上を角速度 ω で回る点の座標は (A cos(ωt+φ), A sin(ωt+φ))。速度は接線向きで大きさ Aω、加速度は中心向きで大きさ Aω²。この3つを変位の軸に落とすだけで、微分せずに v と a が出る。

POSITION
x = A cos(ωt+φ)
VELOCITY
v = −Aω sin(ωt+φ)　（円運動の速度 Aω の影）
ACCELERATION
a = −Aω2 cos(ωt+φ) = −ω2x

最後の式には時間も三角関数も残っていない。加速度が変位に比例して逆向きという関係が見つかれば、それは単振動で、比例定数の平方根がそのまま ω になる。使うのはほぼこの一行。

2つの振り子が同じ式に落ちる

SPRING
m·d2x/dt2 = −kx　→　ω = √(k/m)、T = 2π√(m/k)
PENDULUM
mL·d2θ/dt2 = −mg sinθ　→（sinθ ≒ θ）→　ω = √(g/L)、T = 2π√(L/g)
COMMON FORM
T = 2π√(慣性 ÷ 復元の強さ)　　m/k ↔ mL2/(mgL) = L/g

単振り子で質量が消えるのは、復元力も慣性も m に比例して約分されるから。ばねでは k が m と無関係なので m が残る。鉛直ばねの場合は、つり合いの位置 x₀ = mg/k を新しい原点に取り直すと重力の項がそのまま消えて、水平ばねと同じ式になる。周期は向きにも振幅にも依らない。

厳密な周期の出し方

エネルギー保存から θ′ = √(2g/L)·√(cosθ − cosθ₀) なので、周期は次の積分になる。

RAW INTEGRAL
T = 4√(L/2g) ∫0θ₀ dθ / √(cosθ − cosθ₀)

これは θ→θ₀ で分母が 0 になる。可積分な特異点なので値は有限だが、シンプソン則をそのまま当てると桁が落ちる。sin(θ/2) = k·sinφ、k = sin(θ₀/2) と置換すると特異点が消える。

ELLIPTIC FORM
T = 4√(L/g)·K(k)、　K(k) = ∫0π/2 dφ / √(1 − k2sin2φ)
AGM
a0=1, b0=√(1−k2)　→　an+1=(an+bn)/2, bn+1=√(anbn)　→　K(k) = π/(2a∞)

算術幾何平均は2次収束するので、倍精度なら5回で止まる。このページの厳密値は全部この方法で出している。検算に使った RK4 は θ″ = −(g/L)sinθ を直接積分し、θ が 0 を横切る時刻を線形補間で拾って周期にしたもの。上のカードで両者の差を表示している。

エネルギー

KINETIC
K = ½mv2 = ½mA2ω2 sin2(ωt+φ)
POTENTIAL
U = ½kx2 = ½mω2A2 cos2(ωt+φ)
TOTAL
E = K + U = ½kA2（一定）、時間平均は ⟨K⟩ = ⟨U⟩ = E/2

単振り子の位置エネルギーは厳密には mgL(1−cosθ)。θ² まで展開すると ½mgLθ² となり、弧の長さ s = Lθ を使えば ½(mg/L)s² という放物線になる。本物の谷は放物線より外側で寝ているので、大きく振ると戻るのに余計に時間がかかる。周期が伸びる理由をポテンシャルの形として見られるのがここ。

使った定数

重力加速度は標準重力 9.80665 m/s²（国際的に決められた定義値）を既定にした。教科書の 9.8 と、東京付近の実測にあたる 9.798 も切り替えられる。9.80665 と 9.798 の差は 0.09% だが、周期は √g で効くので影響は 0.046% に縮む。単振り子を 30° まで振ったときのずれ 1.74% と比べれば、g をどれにするかは些細な話だと分かる。どれを使って計算しているかは MODEL カードに出している。

ばね定数 k と質量 m、糸の長さ L は入力値。振幅 A は cm で入れて、エネルギーの計算のときだけ m に直している。

取り違えやすいところ

  • 単振動の周期は振幅に依らない。ただしそれは a = −ω²x が厳密に成り立つ場合の話で、単振り子ではもともと成り立っていない。
  • v が最大になるのは中心、a が最大になるのは端。同時に最大になることはない。
  • 単振り子の復元力は張力ではなく重力の接線成分。張力は円の中心を向いていて、接線方向の運動には効かない。
  • 鉛直ばねで「重力があるから周期が変わる」と考えない。原点をつり合いの位置に移せば消える。
  • エネルギーの式の k は、単振り子では mg/L のこと。ばね定数と同じ役をしている。
