SYSTEMATIC SEPARATION · 04

有機化合物の系統分離
pKa の序列で決まる分液の論理

分液漏斗の各段階で水層の pH を電荷収支から解き、分配係数と合わせて各成分の行き先を厳密に計算します。操作の順序と試薬を入れ替えて、分離が失敗するところまで試せます。医学部受験向け。

THE RULE AND WHAT IT RESTS ON

教科書の判定則の中身

「加えた塩基の共役酸の pKa より強い酸だけが塩になって水層へ」という規則は、プロトン移動の平衡定数そのものです。

HA + HCO₃⁻ ⇌ A⁻ + H₂CO₃ K = Ka(HA) / Ka₁(H₂CO₃) = 10^(6.35 − pKa)

分母に来るのが加えた塩基の共役酸の Ka。あとは指数の引き算だけです。カルボン酸 4.2 とフェノール 9.9 のあいだに H₂CO₃ の 6.35 が挟まっている、これが分離が成立する唯一の理由で、炭酸水素ナトリウムに特別な性質があるわけではありません。

だから炭酸ナトリウムに変えると壊れます。共役酸が HCO₃⁻ になって基準が pKa 10.33 に上がり、フェノールも K = 2.4 で反応してしまう。同じ「炭酸のナトリウム塩」でも1段目を使うか2段目を使うかで基準が4桁ずれます。

実際に効いているのは水層の pH

平衡定数は「反応が進むか」を教えますが、何割が移るかは決めません。決めるのは水層の pH と、中性形の分配係数 P です。中性形だけがエーテルに溶け、イオン形は水層に留まる。

n = [HA]水 · ( P·V有機 + (1 + Ka/h)·V水 ) 水層への移行率 f = (1 + Ka/h)·V水 / ( P·V有機 + (1 + Ka/h)·V水 ) 等体積で f = 1/2 を解くと 酸 pH₅₀ = pKa + log(P − 1) 塩基 pH₅₀ = pKa(BH⁺) − log(P − 1)

半分が水層に移るのは pKa ではなく pKa + log P。油に溶けやすい物質ほど、水層へ引き出すのに強い試薬が要ります。安息香酸（pKa 4.20、P 100）の pH₅₀ は 6.20 で、炭酸水素ナトリウムの水層 pH 7〜8 をぎりぎり下回っているにすぎません。

水層の pH も固定ではない

g(h) = h − Kw/h + [Na⁺] − [Cl⁻] + Σ[BH⁺] − Σ[A⁻] − C炭酸·z̄(h) = 0

テーマ2の塩の式に、有機成分が分配で持ち込む [A⁻] と [BH⁺] が加わった形です。各項が h について単調なので、ここでも二分法が一意解に収束します。

0.5 mol/L の炭酸水素ナトリウム 20 mL に安息香酸 1 mmol を入れると HCO₃⁻ が 1 mmol 消費され、pH は 8.34 から 7.33 へ下がる。消えた 1 mmol がそのまま発泡として見えます。フェノールを入れても泡が出ないという識別法の正体がこれです。

操作の組み立て

エーテル 20 mL に各成分 1.00 mmol ずつ。各操作で新しい水溶液 20 mL を使って振り、水層を捨てます。抽出回数を増やすと目的物の回収率は上がりますが、他の成分も一緒に持っていかれます。

pKa NUMBER LINE

判定の根拠

上段が酸、下段が塩基（共役酸の pKa）。破線が加えた塩基の共役酸の pKa で、これが教科書の判定基準。実線が実際の水層 pH です。酸は基準より左（強い酸）が、塩基は基準より右（強い塩基）が水層へ移ります。

EXTRACTION CURVES

水層への移行率

縦軸は各成分が水層へ移る割合。曲線が 0.5 を横切る pH が pH₅₀ = pKa ± log(P−1) で、pKa そのものからは log P だけずれています。縦の実線が各操作の水層 pH。

ASSUMPTIONS · ADOPTED VALUES

前提と定数の注記

密閉系として解いています。実際は振ってガス抜きをするので H₂CO₃ が CO₂ として抜け、水層の pH は計算値より高く保たれて抽出効率は上がります。この計算は保守側の見積もりです。

分配係数はエーテル／水の概算値。文献値のばらつきが大きく、桁が合っている程度の精度しかありません。入試で数値が与えられることもまずない量です。分離の向きを決めるのが pKa、効率を決めるのが P、と役割を分けて理解してください。

H₂O の pKa は 15.7 を採用。[H₂O] = 55.5 mol/L を分母に取る有機化学の慣用値です。Kw から直接 14 とする流儀もありますが、水酸化ナトリウムの判定基準として使う限り結論は変わりません。

イオン形はエーテルに溶けないものとしています。実際にはイオン対として少量が有機層に残ることがあり、とくに大きな有機イオンでは無視できません。
