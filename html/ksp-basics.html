溶解度積 ― 沈殿するかしないかを数で決める

医学部受験の無機化学で問われる沈殿平衡を、近似に頼らず解いて可視化する。イオン積による判定、溶解度と Ksp の換算、共通イオン効果までを扱う。硫化物の分別沈殿と両性水酸化物は別ファイル。

1 · Q vs Ksp

混ぜたら沈殿するか

2つの溶液を混ぜた直後の濃度からイオン積 Q を計算し、Ksp と比べる。Q が Ksp を超えていれば、超えた分だけ沈殿して Q は Ksp まで落ちる。残留濃度は「完全に沈殿する」と仮定せず、平衡式を直接解いた値を出している。

Ksp = [A]m[B]n   /   Q = [A]0m[B]0n   /   [A]0 = c1V1/(V1+V2)
2 · Solubility ⇄ Ksp

化学式の型で換算式が変わる

純水に s mol/L 溶けたとき [A] = ms、[B] = ns。これを Ksp の定義に代入すると型ごとの係数 mmnn が出る。この係数のせいで、Ksp が小さい塩のほうが溶けやすいという逆転が起きる。

Ksp = mmnn·sm+n  ⟹  s = (Ksp / mmnn)1/(m+n)

難溶性塩の一覧

水酸化物は公式だけでは足りない

水酸化物の溶解度を Ksp = mmnnsm+n で求めるのは、水の電離を無視した近似。塩から出る OH⁻ が 10⁻⁷ mol/L より少ない場合、実際の [OH⁻] は水由来のぶんで底上げされる。電荷収支 n[Mn+] + [H⁺] = [OH⁻] と Kw を連立して解いた値を並べた。

n·Ksp/[OH⁻]n + Kw/[OH⁻] = [OH⁻]
3 · Common Ion Effect

共通イオンを加えると溶解度が落ちる

共通イオンを c mol/L 加えた溶液での溶解度 s は、質量作用の式を s について解いて求める。左辺は s の単調増加関数なので、二分法で厳密に解ける。高校で使う近似は溶けた分の寄与を無視した形で、c が小さくなると成り立たなくなる。

厳密  (ms + cA)m(ns + cB)n = Ksp   /   近似  s ≈ Ksp / (mmcBn) など
厳密解 近似解 Ksp/cⁿ（細線） 純水での溶解度
塩効果。共通イオンを含まない電解質(KNO₃ など)を加えると、イオン強度が上がって活量係数が 1 を下回り、溶解度はむしろ増える。0.1 mol/L 程度の 1:1 電解質で AgCl の溶解度は 2 割ほど増加する。高校では活量を扱わないためこの計算には含めていない。

定数の出典と注記

Ksp は 25 ℃ の値。ハロゲン化銀・硫酸塩・炭酸塩は CRC Handbook と日本の高校教科書でほぼ一致する。以下は食い違いのあるもの。

Ca(OH)₂ 5.0×10⁻⁶ を採用。文献値は 4.7×10⁻⁶ 〜 8.0×10⁻⁶ に散らばり、溶解度実測(0.0165 mol/L, 25 ℃)から逆算すると 1.8×10⁻⁵ になる。イオン対 CaOH⁺ の生成を無視しているためのずれ。
Al(OH)₃ 1.3×10⁻³³ を採用。無定形は 3×10⁻³³ 前後、結晶質のギブサイトは 1×10⁻³⁴ 程度まで下がる。
Fe(OH)₃ 6.3×10⁻³⁸。水和酸化物の状態でひと桁以上変動する。
Ca₃(PO₄)₂ 2.0×10⁻²⁹。PO₄³⁻ の加水分解が大きいため、この Ksp から出した溶解度は実測(約 2×10⁻⁵ mol/L)と 2 桁ずれる。表の値は加水分解を無視した理論値。

硫化物の Ksp は S²⁻ の濃度スケールの取り方で 10⁵ 倍以上変わるため、このファイルには含めていない。別ファイルで扱う。
