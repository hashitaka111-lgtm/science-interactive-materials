MOMENTUM & IMPULSE

運動量と力積インタラクティブ

2つの物体が正面衝突するとき、外力(摩擦など)がなければ運動量の合計は衝突の前後で変わらない。一方で運動エネルギーは、衝突のしかた(反発係数 e)によって保たれることもあれば失われることもある。力積は「衝突の瞬間だけに働く力の効果」で、運動量の変化量そのものであり、2物体には向きが逆で大きさが等しい力積(作用・反作用)が働く。このページでは1次元(正面衝突のみ、斜め衝突は扱わない)でこの3つの関係を確かめる。

SIMULATOR

衝突のしかた(反発係数 e)を選んで運動量・力積を見る

質量 m1・m2 と衝突前の速度 v1・v2(符号は向きを表し、正が右向き)はどのモードでも自由に変えられる。衝突後の速度 v1′・v2′ は運動量保存則と反発係数の式から自動で計算される値で、直接操作することはできない。

衝突のしかた
物体1・運動量 p1 物体2・運動量 p2 力積 J1(物体1が受ける) 力積 J2(物体2が受ける・J1と逆向き同じ大きさ)

円の大きさは質量の目安として模式的に描いているだけで、実際の物体の大きさとは無関係(点として扱う質点モデル)。速度そのものは矢印では示さず、下の数値パネルの数字で確認する(運動量ベクトルと単位が異なるため、矢印を混在させない)。運動量 p と力積 J は単位が同じ(kg·m/s)なので、矢印の長さは共通の物差し(px/(kg·m/s))で描いている—衝突前後で運動量の矢印の長さがどう変わるかを、力積の矢印の長さと見比べられる。

VECTORS

運動量の矢印は衝突の瞬間に切り替わり、力積の矢印はその瞬間だけ現れる

物体1・物体2の運動量ベクトルは軸に沿った矢印で、時刻が衝突時刻 tc を境に衝突前の値(m1v1・m2v2)から衝突後の値(m1v1′・m2v2′)へ切り替わる。長さは速さでなく運動量の大きさに比例し、向きは符号(右向きが正)で決まる。

力積の矢印(J1・J2)は t = tc の前後ごく短い間だけ衝突点に現れる。J1 と J2 は大きさが同じで向きが逆(作用・反作用)なので、もし同じ位置・同じ色で描くと1本の矢印にしか見えなくなってしまう。この教材ではJ1を軸の上側、J2を軸の下側の別の行に離し、色も別々にすることで、逆向き2本の矢印であることが常に見分けられるようにしている。

EQUATIONS

運動量保存則と反発係数から衝突後の速度を求める

右向きを正とし、質量 m1・m2、衝突前の速度 v1・v2、衝突後の速度 v1′・v2′、反発係数 e(0≤e≤1)とする。

運動量保存則
m1v1 + m2v2 = m1v1′ + m2v2′
反発係数の定義
e = −(v1′ − v2′) / (v1 − v2)　　(e=1: 完全弾性衝突、e=0: 完全非弾性衝突)
連立を解いた結果(このシミュレーションが使う式)
v1′ = { (m1−e·m2)v1 + (1+e)m2v2 } / (m1+m2)
v2′ = { (1+e)m1v1 + (m2−e·m1)v2 } / (m1+m2)
力積(運動量の変化量。作用・反作用で符号が逆になる)
J1 = m1v1′ − m1v1　　J2 = m2v2′ − m2v2 = −J1

e=1(弾性衝突)では運動エネルギー合計は衝突前後で変わらない。e=0(完全非弾性衝突)ではv1′=v2′(2物体が一体になって動く)になり、運動エネルギーは衝突の前より必ず小さくなる(0<e<1ではその中間)。運動量の合計はeの値によらず常に保存される—数値パネルの「合計運動量」が時刻によらず一定であることで確認できる。
