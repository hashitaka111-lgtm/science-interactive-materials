# periodic-trends.json 検証資料

`data/periodic-trends.json`(周期表と周期律、第1〜4周期の典型元素26種+第5〜7周期の典型元素18種)
を、人間が化学的な正しさの観点で検証するための資料。

## 対象範囲についての訂正

指示文は精密対象を「第1〜4周期の典型元素24種」としていたが、実際に列挙された元素記号
(H, He / Li, Be, B, C, N, O, F, Ne / Na, Mg, Al, Si, P, S, Cl, Ar / K, Ca, Ga, Ge, As, Se, Br, Kr)
を数えると 2+8+8+8=26種になる。第4周期の典型元素だけでも8種あり(遷移元素Sc〜Znを除いた
K, Ca, Ga, Ge, As, Se, Br, Kr)、これは他の周期と同数なので「24種」という総数のほうが
数え間違いと判断し、列挙された元素記号のほうを正として26種すべてを収録した。
第5〜7周期は指示どおり18種(Rb〜Xe 8種・Cs〜Rn 8種・Fr, Ra 2種)。
合計は「24+18=42件」ではなく「26+18=44件」になっている。

## 原子半径(共有結合半径、pm)

**採用した定義**: Cordero et al. (2008) *Dalton Trans.* 37, 2832–2838の共有結合半径(単結合・低スピン)。

共有結合半径の標準セット。炭素のみ混成により複数値(sp3=76pm, sp2=73pm, sp=69pm)を持つため、

違いを区別するためconfidenceを一段階下げた。

## 第一イオン化エネルギー(kJ/mol)

## 電気陰性度(ポーリングスケール)

**出典**: Allred, A. L. (1961) *J. Inorg. Nucl. Chem.* 17, 215–221の改訂ポーリングスケール
(熱化学データに基づく再計算値)。フッ素はこの論文の値とCRC Handbookの値が一致している。

| 元素 | 値 | 元素 | 値 | 元素 | 値 |
|---|---|---|---|---|---|
| H | 2.20 | Na | 0.93 | K | 0.82 |
| He | null | Mg | 1.31 | Ca | 1.00 |
| Li | 0.98 | Al | 1.61 | Ga | 1.81 |
| Be | 1.57 | Si | 1.90 | Ge | 2.01 |
| B | 2.04 | P | 2.19 | As | 2.18 |
| C | 2.55 | S | 2.58 | Se | 2.55 |
| N | 3.04 | Cl | 3.16 | Br | 2.96 |
| O | 3.44 | Ar | null | Kr | null |
| F | 3.98 | | | | |
| Ne | null | | | | |

### nullになる元素とその理由

He・Ne・Ar・Kr(貴ガス4種)を電気陰性度nullとした。これらは化学的にほぼ不活性で、
共有結合を形成しないため電気陰性度そのものが定義されない、というのが高校化学の標準的な扱い。

ただし例外として、**Krのみ一部の文献(CRC Handbook等)がKrF2のような希少な化合物の存在を
根拠に推定値3.00を与えている**。この教材では「貴ガスは基本的にnull」という指示に従い、
高校化学の慣例を優先してKrもnullとした。He・Ne・Arについては、そもそも安定な化合物が
知られておらず(2026年現在)、推定値を与える文献も見当たらなかった。

### 情報源間で数値が割れていた箇所

主要な情報源間(Allred 1961・CRC Handbook・Wikipedia集約表)で、上記22元素の数値に
実質的な食い違いは見られなかった。いずれも小数第2位までほぼ完全に一致している。

### 参考: 日本の高校教科書・資料集で使われる丸め方について(実装時の判断材料)

添付された手書きノートの電気陰性度の値(H=2.1, Li=1.0, Na=0.9, K=0.8, C=2.5, N=3.0, O=3.5,
F=4.0, Br=2.8など)は、上記の学術的な値(H=2.20, Li=0.98, Na=0.93, K=0.82, C=2.55, N=3.04,
O=3.44, F=3.98, Br=2.96)を**小数第1位に丸めた値**と一致する。これは日本の高校化学の教科書・
資料集で広く使われている慣例的な丸め方であることをWeb調査で確認した。

この教材のdata/periodic-trends.jsonには学術的な精度の値(小数第2位)をそのまま収録した。
HTML実装時にどちらの精度で表示するかは、instruction文に明示がないため実装段階の判断に
委ねる。医学部受験生が資料集や過去問で見慣れているのは丸めた値である可能性が高い点は
留意事項として記録しておく。

## 分類・状態・価電子・酸化数・炎色反応について

指示により「確立した知識としてそのまま確定値でよい」区分としたため、個別の出典調査は
行っていない。以下、判断に迷った点のみ記録する。

- **アルカリ金属からのHの除外**: 水素は1族に属するが、高校化学の慣例に従いアルカリ金属には
  分類せず「非金属」とした(添付の手書きノートでもHから「非金属」への矢印で区別されている)
- **アルカリ土類金属の範囲**: Be・Mgはアルカリ土類金属に含めず「典型金属」とした
  (添付の手書きノートでもオレンジ枠がCa・Sr・Ba・Raのみを囲んでおり、Be・Mgは枠外)
- **半金属の範囲**: B, Si, Ge, As, Sb, Teの古典的な6元素セットを採用した。Po・Atは金属寄り・
  ハロゲン寄りの性質を両方持つ境界元素で、資料によって半金属とする場合と典型金属/ハロゲンと
  する場合があるが、この教材ではPoを典型金属、Atをハロゲン(族による分類)とした
- **価電子数と最外殻電子数の区別**: 添付の手書きノートが両者を別の行として明示的に区別していた
  (18族は価電子=0だが最外殻電子数=8、Heのみ最外殻電子数=2)ため、この教材でも
  `valenceElectrons`と`outermostShellElectrons`を別フィールドとして持たせた
- **ガリウム・セシウムの状態**: 常温(25℃)でともに固体だが、Ga(融点29.76℃)・Cs(融点28.44℃)
  は融点が室温にきわめて近いことで知られる元素。noteフィールドに明記した
- **At・Frの常温での状態**: 天然にはごく微量(Atは地殻中に推定30g未満、Frは最も安定な同位体でも
  半減期約22分)しか存在せず、バルクとしての常温での状態は実測されたことがない。理論的には
  固体と予測されているが「実測ではない」ため、この教材ではnullとして未確定を明示した
  (それらしい値を作らない、という方針に従った)

## 既存教材との重複回避について

化学の既存教材のうち、原子の構造・電子配置を扱う教材は現時点で存在しない(coverage-map.md
参照)。ヘンリーの法則(気体の溶解)・溶解度曲線とは扱う対象がまったく異なり、重複はない。
