## 3. 保留にした反応

収録を見送ったもの。「反応が存在しない」ものは1件もない。理由は範囲の判断か、表記への自信のなさか、系統図としてのつながりのどれか。

### 3-1. 範囲外と判断したもの

| 見送った反応 | 理由 |
|---|---|
| アセチレン + HCl → 塩化ビニル | 反応は教科書にあるが、塩化ビニルは付加重合の単量体としてしか出てこない。今回は高分子を除外しているため。 |
| アセチレン + 酢酸 → 酢酸ビニル | 同上。 |
| アセチレン + HCN → アクリロニトリル | 同上。さらに現行課程では扱いが小さい。 |
| p-キシレン → テレフタル酸（酸化） | PETの原料で、高分子側の内容。 |
| 油脂 + NaOH → セッケン + グリセリン（けん化） | 反応は確実だが、油脂・セッケン・グリセリンの3ノードが他とつながらない独立した島になる。今回は見送り、次回対応とする。 |
| ギ酸 → 一酸化炭素（濃硫酸で脱水） | 反応は確実。ただし生成物が無機物で、有機の系統図に置くとノードの性格がそろわない。 |
| グルコースのアルコール発酵 → エタノール | 天然有機化合物・高分子側の内容。 |
| シュウ酸、マレイン酸、フマル酸 | 二価カルボン酸・幾何異性体の話題で、構造決定寄り。系統図の枝としてつながらない。 |

### 3-2. 表記に自信がなく、lowでも収録を見送ったもの

| 見送った反応 | 理由 |
|---|---|
| 酢酸カルシウムの乾留 → アセトン | 古い製法で、現行の教科書での扱いに自信がない。載っていない教科書がある可能性が高いと判断した。 |
| ナフタレンの酸化 → 無水フタル酸 | 触媒（酸化バナジウム(V)）の表記に自信がなく、確認できていない。 |
| アルデヒド → アルコール、ケトン → アルコール（還元） | 「酸化の逆」として一般論では書かれるが、教科書が還元剤を具体的に指定しないため、reagent 欄に書ける試薬名がない。 |
| アセトアニリド + 水 → アニリン + 酢酸（加水分解） | アミドの加水分解が高校の範囲として問われるかの判断がつかなかった。 |
| アセチレン + アンモニア性硝酸銀 → 銀アセチリド | 教科書によって載っていない。 |

### 3-3. 反応は確かで、規模を理由に落としていたが今回復元したもの

前回は規模を抑えるために見送ったが、今回の指示で復元した。

- ベンゼン + Cl2（光） → 1,2,3,4,5,6-ヘキサクロロシクロヘキサン（r056）
- トルエン → ベンズアルデヒド → 安息香酸（r057・r058）。ベンズアルデヒドをノードとして追加し、既存の「トルエン→安息香酸」（r052、直接酸化）とは別経路として両方収録した。

### 3-4. 反応としては立てず、ノードの detection に入れたもの

次は「反応」ではなく「検出」としてノード側に持たせた。生成物（ヨードホルム CHI3、2,4,6-トリブロモフェノールなど）はノード化していない。

- ヨードホルム反応（エタノール、2-プロパノール、アセトアルデヒド、アセトン）
- 銀鏡反応、フェーリング液の還元（ホルムアルデヒド、アセトアルデヒド、ギ酸）
- 銀鏡反応のみ（ベンズアルデヒド。芳香族アルデヒドはフェーリング液を還元しない）
- 塩化鉄(III)水溶液による呈色（フェノール・サリチル酸・サリチル酸メチル）
- 臭素水によるフェノールの白色沈殿
- さらし粉水溶液によるアニリンの赤紫色、二クロム酸カリウムによる黒色（アニリンブラック）
- 炭酸水素ナトリウム水溶液からのCO2発生（酢酸・ギ酸・安息香酸・サリチル酸）

### 分類の注記

- **炭化カルシウム CaC2** — `family` を「無機化合物」にした（今回新設した枠）。アセチレンの出発点として必要なので系統図には残す。`group` に対応する分類がないため「その他」のまま。
- **シクロヘキサン C6H12** — ベンゼンから生じるが、化合物としては脂環式で芳香族ではないため `family` は「脂肪族」。
- **1,2,3,4,5,6-ヘキサクロロシクロヘキサン C6H6Cl6** — ベンゼンへの付加でできるため芳香環が残っておらず、`family` は「脂肪族」。
- **ベンズアルデヒド C6H5CHO** — 芳香環にホルミル基が直結。銀鏡反応は陽性だが、脂肪族アルデヒドと異なりフェーリング液は還元しない。

### 塩の扱い

酢酸ナトリウム・ナトリウムフェノキシド・アニリン塩酸塩などの塩は、もとの官能基の `group`（カルボン酸／フェノール類／アミン）に入れている。ベンゼンスルホン酸とその塩だけは該当する分類がないので「その他」。
