# organic-properties.json 検証資料

`data/organic-reaction-map.json` の全47ノードについて作成した性質データ
（`data/organic-properties.json`）を、化学的な正しさの観点で1回で検証するための資料。

## 更新履歴

初版作成後、以下3件を修正した（指示に基づく修正。この資料はその反映版）。

| 化合物 | 変更内容 |
|---|---|
| ピクリン酸 | acidity「フェノール性」→「強酸」。nahco3_reactionはtrueのまま。confidence「low」→「high」 |
| アニリン | bromine_water「なし」→「白色沈殿」（2,4,6-トリブロモアニリン生成）。confidence「low」→「high」 |
| サリチル酸 | bromine_water「なし」→「白色沈殿」（フェノール性OHによる置換）。confidence「low」→「high」 |

これに伴い、以下の集計値が初版から変化している。

- confidence: high 29件→**32件**、low 18件→**15件**
- 臭素水で白色沈殿する化合物: 1件→**3件**
- 検出反応プロファイルが完全一致するグループに、新たに**ピクリン酸とベンゼンスルホン酸の2件**が加わった（詳細は「一意に決まらない組み合わせ」参照）

## 一意に決まらない組み合わせ

検出反応（酸性度・NaOH・NaHCO3・HCl・ヨードホルム・銀鏡・フェーリング・FeCl3・臭素水・さらし粉）
だけを見ると、以下のグループ内では互いに区別できない。ただし**分子式・分子量・官能基**は
グループ内でも全て異なるため、これらを絞り込み条件に含めれば区別できる。
逆引きUIでは検出反応だけで「1件に絞れた」と誤認させない設計が必要（実装タスク側への申し送り）。

- **中性・無反応（19件）**: 炭化カルシウム、メタン、エタン、シクロヘキサン、クロロメタン、
  1,2-ジブロモエタン、メタノール、ジエチルエーテル、無水酢酸、酢酸エチル、ベンゼン、トルエン、
  クメン、クメンヒドロペルオキシド、クロロベンゼン、ニトロベンゼン、アセトアニリド、
  2,4,6-トリニトロトルエン、1,2,3,4,5,6-ヘキサクロロシクロヘキサン
  （炭化カルシウムは無機化合物のため別枠。他18件は分子式・官能基で区別可能）
- **中性・臭素水で脱色のみ（3件）**: エチレン、プロペン、アセチレン（分子式・二重結合/三重結合で区別可能）
- **中性・ヨードホルムのみ陽性（3件）**: エタノール、2-プロパノール、アセトン（分子式・官能基で区別可能）
- **塩・無反応（8件）**: ナトリウムエトキシド、酢酸ナトリウム、アニリン塩酸塩、塩化ベンゼンジアゾニウム、
  ナトリウムフェノキシド、ベンゼンスルホン酸ナトリウム、安息香酸ナトリウム、サリチル酸ナトリウム
  （分子式・官能基で区別可能）
- **カルボン酸・NaOH可溶かつNaHCO3反応のみ（3件）**: 酢酸、安息香酸、アセチルサリチル酸
  （分子式・官能基で区別可能。ギ酸・サリチル酸は追加の呈色反応があるため別グループ）
- **強酸・NaOH可溶かつNaHCO3反応のみ（2件）**: ピクリン酸、ベンゼンスルホン酸
  （修正で新たに生じたグループ。ピクリン酸のacidityを「フェノール性」から「強酸」に変更した結果、
  この9項目の検出反応プロファイルがベンゼンスルホン酸と完全に一致するようになった。
  分子式（C6H3N3O7 と C6H6O3S）・分子量・官能基（ニトロ基とヒドロキシ基 vs スルホ基）で区別可能。
  逆引きUIでこの2件が並んだ場合、「検出反応だけでは決まらない」ことを必ず示す必要がある）

## confidence が low の件

| 化合物名 | 迷った項目 | 理由 |
|---|---|---|
| 炭化カルシウム | 検出反応全般 | 無機化合物のため有機の検出反応の枠組みが適用できない（指示に基づき全項目false/空文字とした） |
| ナトリウムエトキシド | 酸性度分類・官能基 | アルコキシドで「塩」のどれにも正確には一致しない。官能基欄も本来は「ヒドロキシ基のHがNaに置換された状態」でヒドロキシ基そのものではない |
| ギ酸 | 臭素水 | ホルミル基による還元性で臭素水を酸化する可能性があるが、高校教科書の検出反応としては通常扱われないため「なし」とした |
| 酢酸ナトリウム | 官能基 | 塩の状態ではカルボキシ基がイオン化しており、由来官能基として記載してよいか判断が分かれる |
| 無水酢酸 | NaOH反応・ヨードホルム・官能基 | 酸無水物はNaOHで加水分解されるが「溶ける」の定義（酸性物質のナトリウム塩化）とは異なる現象。指定の官能基リストに「酸無水物」がないためカルボニル基のみ記載 |
| クメンヒドロペルオキシド | 官能基 | 過酸化物構造（-OOH）が指定の官能基リストにない |
| アニリン塩酸塩 | 官能基・HCl可溶性 | 既に塩酸塩になっている物質に対する「HClに溶けるか」の判定基準が曖昧 |
| アセトアニリド | 官能基 | アミド結合が指定の官能基リストにない。カルボニル基のみで代替した |
| 塩化ベンゼンジアゾニウム | 酸性度分類・官能基 | ジアゾニウム塩は指定の酸性度分類のどれにも正確には一致しない。ジアゾニウム基も指定の官能基リストにない |
| p-ヒドロキシアゾベンゼン | 酸性度・NaOH溶解性・FeCl3・官能基 | フェノール性OHをもつが、アゾ基共役の影響でFeCl3呈色が起こるかは教科書に記載がない。アゾ基も指定の官能基リストにない |
| ナトリウムフェノキシド | 官能基・FeCl3 | フェノキシドの状態でのFeCl3呈色は教科書に記載がなく「なし」とした |
| ベンゼンスルホン酸ナトリウム | 官能基 | 塩の状態でのスルホ基表記の是非 |
| 安息香酸ナトリウム | 官能基 | 塩の状態でのカルボキシ基表記の是非 |
| サリチル酸ナトリウム | 官能基・FeCl3 | 塩の状態での官能基表記とFeCl3呈色の扱い |
| サリチル酸メチル | NaOH溶解性 | フェノール性OHによる酸性化とエステル結合のけん化が同時に起こりうるため、「NaOHに溶ける」の意味が単純でない |

32件がconfidence: high、15件がconfidence: low。

**ピクリン酸・アニリン・サリチル酸は今回の修正でlowからhighに変更した**（教科書記載の反応として
明確に判断できるようになったため）。上表からは除いた。

## 反応データとの矛盾

`organic-reaction-map.json` の `detection` フィールドと `organic-properties.json` の対応する
項目をスクリプトで突き合わせた結果、**矛盾は0件**（全項目OK）。

ただし以下は「矛盾」ではなく、detectionフィールドがカバーしていない範囲を補った箇所として報告する。

1. **アニリンの「硫酸酸性の二クロム酸カリウムで黒色」**（detection記載あり）は、
   properties.jsonの16キーに対応する項目がないため反映されていない。染料関連の酸化呈色反応で、
   今回の逆引きスキーマ（酸性度・NaOH・NaHCO3・HCl・ヨードホルム・銀鏡・フェーリング・FeCl3・
   臭素水・さらし粉）には含まれない検出反応。
2. NaOH可溶性・NaHCO3反応・HCl可溶性・臭素水・さらし粉の一部は、detectionフィールドに直接の
   記載がなく、noteの記述と一般的な酸塩基性質（カルボン酸はNaOH可溶かつNaHCO3反応、
   フェノール類はNaOH可溶だがNaHCO3非反応、弱塩基はHCl可溶、二重結合・三重結合は臭素水を脱色）
   から補って判定した。該当は主にギ酸・酢酸・安息香酸・サリチル酸・アセチルサリチル酸・
   フェノール・ピクリン酸・p-ヒドロキシアゾベンゼン・サリチル酸メチル・ベンゼンスルホン酸・
   アニリンで、いずれも高校教科書の範囲内の一般則。confidenceが low になっている項目は
   上表の理由欄を参照。
3. **今回の修正3件も、いずれもdetectionフィールドに直接の記載はない。**
   - ピクリン酸のacidity「強酸」: detectionは空配列（`[]`）。ニトロ基3個による酸性度の
     強化は高校教科書で扱われる一般知識として判断した。
   - アニリンの臭素水「白色沈殿」: detectionは`["さらし粉水溶液で赤紫色","硫酸酸性の二クロム酸カリウムで黒色"]`
     で臭素水への言及なし。2,4,6-トリブロモアニリンの生成は教科書記載の反応として指示に基づき追加した。
   - サリチル酸の臭素水「白色沈殿」: detectionは`["塩化鉄(III)水溶液で赤紫色","炭酸水素ナトリウムからCO2発生"]`
     で臭素水への言及なし。フェノール性OHによる置換反応として指示に基づき追加した。
   
   3件とも`organic-reaction-map.json`のdetectionフィールドと矛盾するわけではない（「なし」から
   「あり」への追加であり、detectionに書かれている内容を否定するものではない）が、
   detectionフィールドだけを見ても導けない情報である点は明記しておく。

## 数の確認

以下をスクリプトで検証した。

```python
import json
with open('data/organic-reaction-map.json') as f:
    rmap = json.load(f)
with open('data/organic-properties.json') as f:
    props = json.load(f)

rmap_ids = [n['id'] for n in rmap['nodes']]
prop_ids = [p['id'] for p in props['properties']]

assert len(rmap_ids) == 47
assert len(prop_ids) == 47
assert len(rmap_ids) == len(set(rmap_ids))   # 重複なし
assert len(prop_ids) == len(set(prop_ids))   # 重複なし
assert set(rmap_ids) - set(prop_ids) == set()  # 不足なし
assert set(prop_ids) - set(rmap_ids) == set()  # 余剰なし
assert rmap_ids == prop_ids                    # 順序も完全一致
```

**結果**: 全てのassertが通過。

- reaction-map ノード数: 47
- properties 件数: 47
- id の重複: なし（両ファイルとも）
- properties に不足している id: なし
- properties に余分な id（reaction-mapに存在しない）: なし
- id の並び順: 完全一致
- 各要素のキー構成（16キー）: 全件で指示通りの構成と完全一致
- confidence の値: 全件 "high" または "low" のみ
- acidity の値: 全件、指定7分類のいずれかに合致
- distinguishing の文字数: 全件30字以内
